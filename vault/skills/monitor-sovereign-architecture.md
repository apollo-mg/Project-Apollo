## When to Use
Use this skill when you need to observe the "heartbeat" of the Sovereign Entity Architecture, debug agent interactions, or verify hardware utilization on the RX 9070 XT.

## Procedure
Execute the following commands in separate terminal windows to monitor different subsystems:

1. **The Brain (Raw Compute & Tokens):**
   ```bash
   tail -f /mnt/TG_2TB/Projects/Apollo/qwopus.log
   ```
   *Monitor token generation speeds, prompt evaluation times, and HTTP request arrivals on port 8082.*

2. **The Dialogue (Agentic Loop):**
   ```bash
   tail -f /mnt/TG_2TB/Projects/Apollo/tmp/open-multi-agent/coordinator.log
   ```
   *Watch back-and-forth between Coordinator and Coder, JSON tool calls (bash, file_edit, update_task_status), and success/error states.*

3. **The State-Sync Ledger (Autonomy in Action):**
   ```bash
   watch -n 5 cat /mnt/TG_2TB/Projects/Apollo/CHANGELOG.md
   ```
   *Observe autonomous structural changes and commit history generated by the agents.*

4. **The Hardware (ROCm Telemetry):**
   ```bash
   watch -n 1 rocm-smi
   ```
   *Monitor GPU utilization and VRAM temperature. Core edge temp should stay low while VRAM may reach ~74C+ during inference.*

## Pitfalls and Fixes
- **Symptom:** Logs are not updating.
  - **Cause:** The process (llama-server or coordinator) might have crashed or hung.
  - **Fix:** Check `pgrep -f llama-server` or `pgrep -f apollo_coordinator.ts`. Restart if missing.
- **Symptom:** VRAM temperature spikes over 90C.
  - **Cause:** Airflow is insufficient for high memory bandwidth loads.
  - **Fix:** Ensure Coolercontrol is active and case fans are tied to memory sensors.

## Verification
- Confirm that `qwopus.log` shows periodic `srv log_server_r: done request` entries.
- Confirm that `coordinator.log` shows `[COORDINATOR PHASE]` and `[CODER PHASE]` headers.
