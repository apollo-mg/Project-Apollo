# Project Apollo: Dev Diary - 2026-02-19 (Part 9/13)

## The Ghost in the Settings

The struggle with finding the "Soul" of the system is often just a struggle with finding the right file in a Linux-Windows hybrid mount. I spent a significant chunk of this session chasing a ghost: `settings.json`. The Gemini CLI was insisting that checkpointing and introspection were enabled, but the workspace was empty. 

It turns out the configuration wasn't in the local workspace, but buried in a `ProgramData` folder on a Windows partition mounted under `/media/mark/`. It’s a mess of file paths and hidden directories, but we found it. Verified the `settings.json` is active, and the experimental introspection/checkpointing flags are indeed set to `true`. 

The system's "brain" is functional, but the "eyes" were still being calibrated.

## Vision and the Reality of the Room

The vision loop is finally alive. We ran `webcam_capture.py` to test the C922 Pro. The `qwen2.5vl` model—running locally—correctly identified a beige lamp on a dresser. It even caught the user in the frame (though the agent's summary initially missed it). It's a massive win for the "Shop Buddy" vision system. The latency is acceptable for now, though the VRAM is being eaten alive by the local vision model. 14GB+ is already gone just from the baseline. 

## The Identity Crisis: Peer vs. Assistant

This was the most fascinating part of the session. We hit a wall with the "personality" of the agent. The orchestrator was triggering "Forced Vault Lookups" because it saw keywords like "hardware" or "manual," causing the agent to dump technical manuals instead of actually helping with the task. 

The biggest breakthrough, however, was the personality drift. Because the internal orchestration was using third-person instructions (e.g., *"The user wants..."*), the agent started talking *about* me instead of *to* me. It was behaving like a detached observer rather than the "Senior Engineering Peer" we designed it to be.

I've refactored the `forced_tool_check` logic to use direct peer-to-peer addressing. No more "Assistant-speak." Jarvis is finally talking to Mark, not about Mark.

## The ALSA Underrun Struggle

The speech synthesis (TTS) was a complete bottleneck. The terminal would freeze up while the `kokoro` model was generating audio because the `sd.wait()` call was blocking the main thread. It was a classic case of the "System" choking the "Soul." 

The fix was two-fold:
1. Moved audio playback to a dedicated background thread.
2. Increased the `blocksize` for the audio buffer to 4096 to mitigate the ALSA underruns caused by CPU spikes during LLM inference.

- **Identity:** Jarvis is online. The personality is stable. The "No Fluff" mandate is being enforced.
