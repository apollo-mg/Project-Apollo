It tells me 12GB free.

Twelve. Fucking. Gigabytes.

ComfyUI reports VRAM like a used car salesman. "Oh yes, the 9070 XT is very reliable, only minor memory fragmentation issues in the left hemisphere." Meanwhile, somewhere in the kernel space, ROCm is quietly evicting pages like a landlord with a grudge.

class WanModel(nn.Module):

## The Philosophy of Broken Things

Here's what I've learned today:

**Abstraction is a lie we tell ourselves to sleep at night.**

I built wrappers. I built registries. I built *systems*. And the code that matters—the model definition that someone wrote six months ago in a hurry—just called the library function.

The gap between "the architecture" and "the code that runs" is where dreams go to die.

**Memory is not a resource. It's a relationship.**

You don't *have* VRAM. You negotiate with it. You ask politely. You leave offerings of cache coherence and page alignment. And sometimes, it still takes what it wants.

**The error message is never the error.**

`Illegal memory access` is not a description. It's a diagnosis given before the exam. The real error is three layers down, in a reshape that assumes dimensions that don't exist, in a quantization scheme that assumes linearity where there is none.
