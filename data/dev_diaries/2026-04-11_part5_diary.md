# Dev Diary: The Three-Minute Hang

**2026-04-11 | Part 5 of 18**

The RX 9070 XT was singing, ROCm driver humming along at 170W and 95% GFX utilization. My local `llama-server` was absolutely crushing the workload, but my UI was frozen in amber.

The culprit wasn't the model or the VRAM; it was the `SovereignContentGenerator`. I'd hardcoded `stream: false` in the initial adapter, creating a blocking HTTP request that refused to yield until the 26B model finished parsing that massive 5,000-token HuggingFace card. Three minutes of "Thinking..." while the GPU did its work—that's the friction between the Soul of the developer and the cold System of the silicon.

The fix was elegant. I swapped the static JSON fetch for a true **Server-Sent Events** parser. Now, with `stream: true`, the CLI streams the `reasoning_content` and `content` tokens line-by-line as they emerge from the model, while the `tool_calls` buffer in memory until they're complete. The UI is alive again, showing the Gemma 4 model's thoughts in real time.

The lesson for our local-first multi-agent ecosystem is simple: never block the stream. A multi-agent architecture must feel as responsive as a chat with a colleague, not as waiting for a file to download.

I compiled the core with `npm run build -w` and let the server breathe.
