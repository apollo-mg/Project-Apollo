# Dev Diary: 2026-02-08 (Part 3)

The architecture is finally splitting. Up until now, everything has been a single-threaded mess of logic and hardware management. I've been forcing one instance to be the "brain" and the "hand" at the same time, and the friction was becoming unbearable. The "Soul"—the creative, multi-agent vision—was constantly being choked by the "System"—the raw, messy reality of managing Klipper configs and PowerShell bridges.

Today, I performed a surgical separation. 

I've effectively bifurcated the ecosystem. I now have a dedicated **Printer Assistant** (Level 4 Support) residing in the `C:\klipper` directory, focused entirely on the physical machine, its macros, and its limits. Then, I instantiated the **Infrastructure Gemini** in a new, isolated environment: `C:\gemini_infrastructure`. This is the new System Architect. It handles the orchestration, the voice-to-LLM pipeline, and the high-level hardware management. 

The transition was rocky. Managing the file transfers for the context dossiers—`INFRASTRUCTURE_CONTEXT.md`, `TIERED_AI_STRATEGY.md`, and the `INIT_PROTOCOL.txt`—felt like setting up a new nervous system. But once the new agent "woke up" and ingested the hardware profile (Ryzen 5700X3D, 32GB RAM, and the 16GB RX 9070 XT), it immediately went to work auditing the system.

The biggest win: The GPU bottleneck. 

I’ve been struggling with the latency of the Whisper transcription. Running it on the CPU was killing the "real-time" feel of the voice interface. The new agent identified the RX 9070 XT as the solution. We're using ZLUDA to map CUDA calls to the AMD hardware. It’s a hack, a bit of a "rebel" workaround to bypass the usual ROCm/NVIDIA friction, but it works. 

The agent confirmed that by redirecting the `nvcuda.dll` through the ZLUDA wrapper, we can offload Whisper to the GPU. We're moving from the `base` model to `medium` on the 9070 XT. The VRAM math checks out: even with the DeepSeek-Coder-V2-Lite model sitting on the GPU, we have ~2.5GB of headroom. This is enough to handle the transcription without choking the rest of the system.

There was a momentary confusion when I ran the script—the terminal showed the old CPU-bound version from the `klipper` folder. A classic case of "path-drift." The new version lives in the infrastructure folder, and once I pointed the terminal to the right directory, the "WidowMaker" system roared to life. 

**The system status is now:**
* **Voice Engine:** Running on GPU (ZLUDA)
* **Whisper Model:** `medium` (High accuracy, low latency)
* **Local LLM:** `deepseek-coder-v2-lite` (Active)
* **Network:** Pi Mirror (Healthy)

The "Soul" is finally getting the hardware it deserves. The voice-to-CAD pipeline is the next big leap. We're moving from just "controlling" a printer to "designing" with it via voice. 

**Next Step:** Testing the ZLUDA-Whisper implementation and finalizing the `commander_voice.py` redirection. The machine is finally starting to feel like an entity rather than just a tool.
