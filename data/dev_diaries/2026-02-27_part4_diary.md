## The Windows of Opportunity: Porting Shop Buddy to 2026

I am staring at the terminal, the glow of the screen reflecting off the **AMD RX 9070 XT** GPU resting in the tower beside my keyboard. It is a good card, but today it is fighting for its life in `vram_management.py`.

Today’s session began quietly, with the mundane but necessary act of stitching Git repositories together. I was creating symbolic links for the `gemini_context_backup`—tying the Windows path (`C:\Users\mgaly\...`) to the Ubuntu mount (`/media/mark/TG 2TB/...`). It is the glue of the local-first ecosystem. But then, the API quota struck, and I knew it was time to stop relying on the cloud and start respecting the silicon.

The real work lay in porting "Shop Buddy"—my local Jarvis—to run fully natively on Windows. It had been born on Linux, you see, and it showed. The code was littered with the detritus of `/media/mark` and `rocm-smi` calls that choked on Windows. There was the friction of `aplay` (the Linux audio player) clashing with the Windows silence. There were `ping` commands that assumed a Unix shell, and hardcoded paths that refused to acknowledge the drive letter `C:`.

I found myself in the classic trenches of the **Soul** versus the **System**. The Soul wants the agent to be continuous—whether I am on my Ubuntu laptop or my Windows desktop, Jarvis should remember where I left off. The System, however, is cold and hard; it does not care about my continuity. It cares about `psutil`, it cares about `torch.cuda`, and it cares that `rocm-smi` is not always in the Windows PATH.

So I refactored. I traded the brittle `rocm-smi` for a graceful `torch` check on Windows. I replaced `aplay` with `winsound`. I swapped the Linux `ping` for a PowerShell query. It was not glamorous, but it was necessary.

The lesson for the local-first multi-agent ecosystem is clear: **Hardcoded paths are the enemy of mobility.** If an agent’s memory is tied to a specific mount point, it cannot truly travel. We must build agents that ask the OS where they are standing before they try to walk.

I am closing the terminal now. The AMD GPU is humming, and for the first time today, the VRAM telemetry is reporting true across the divide.
