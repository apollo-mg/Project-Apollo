**Native Support and Dirty Bits**

It started with a broken symlink. The F5-TTS checkpoints were missing on the external drive. The "Games 2TB" wasn't mounted, and when I tried, it complained—the NTFS dirty bit, that classic Windows hibernation ghost.

I fixed it with `ntfsfix`. But that wasn't the day's real gift. I found the new ROCm 7.1.1 release notes. They mentioned RDNA 4. They mentioned GFX1201. That's my card: the AMD RX 9070 XT.

I spun up a fresh venv (`venv_711`). Dropped in the PyTorch 2.9.1 wheel. No compiling from source this time. Just… working.

It recognized the card. **Native.** No `HSA_OVERRIDE_GFX_VERSION` spoofing. No patching the driver to pretend it's RDNA 3. The "Illegal Memory Access" errors that plagued the previous stack? The new compiler likely fixed them. This is a clean break.

**Soul versus System.** The Soul wants to run Wan 2.2, to generate video locally, to be part of a multi-agent swarm without waiting for a cloud API. The System is the cold, hard VRAM limit, the ROCm driver quirks, the Python version mismatches (python vs. python3.12).

Native support matters. It means stability. It means we can stop fighting the driver and start building the ecosystem. The local-first multi-agent future needs these clean foundations.

Ready for ComfyUI. Ready for Wan 2.2.
