**Dev Diary: 2026-02-20 (Part 4)**

The AMD RX 9070 XT is humming softly on the desk. The VRAM guard just fired again—14620 MB creeping past the 14500 MB threshold. It's a small margin, but in this local-first experiment, margins are everything.

Today was about the agent's voice. DeepSeek was still chatty, padding the response with "I've located the Octopus Pro PDF..." before delivering the goods. For a voice agent, that preamble adds precious seconds. So we killed it. We also silenced the `duckduckgo_search` warnings that cluttered the console. The goal: high-density, engineering-grade specs without fluff.

The epiphany came with the tool call. The agent mustn't hallucinate bash commands; it must use the JSON tool. We hardened `handle_actions` to be forgiving—accepting `command` as a key, mapping bash blocks to `run_bash`. The friction between the "Soul" (the desire for instant, conversational recall) and the "System" (the cold VRAM limit, the strict tool interface) is the whole story of this project.

Core lesson: In the local-first multi-agent ecosystem, trust is built on deterministic tool use, not probabilistic chatter. Every millisecond and every kilobyte counts.
