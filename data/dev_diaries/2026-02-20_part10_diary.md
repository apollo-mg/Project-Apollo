# Project Apollo: Dev Diary - 2026-02-20

## The Chaos of Multi-Step Logic

Today was a grind of cleaning up the "ghosts" in the machine. I spent the first chunk of the session refactoring the model constants. The system was a mess of hardcoded strings for the `hermes3` and `deepseek` models scattered throughout `buddy_agent.py`. I moved them into `llm_interface.py` to create a single source of truth. It’s a small architectural win, but it prevents that "brain transplant rejection" feeling when I inevitably want to swap in a more efficient quantized version of the Engineer.

The real headache, though, was a persistent `RuntimeWarning` from `duckduckgo_search`. The library author renamed the package to `ddgs`, and even though I tried to suppress the warning, the import was firing before the filter could take hold. I had to broaden the suppression regex just to keep the logs clean. Noise is the enemy of debugging.

## The "Lost Instructions" Bug

The most critical moment of the session came during the real-time vision test. I had the agent scanning the pegboard, and it correctly identified a bunch of tools (Impact Driver, T-Handle, etc.) that were missing from our `shop_inventory.json`. 

But when the Engineer (DeepSeek) tried to update the inventory, it outputted multiple JSON blocks in a single response. I realized my `handle_actions` function was using `re.search`, which only grabs the *first* match. The agent was seeing the whole world, but only acting on the first thing it saw. 

I ripped it out and replaced it with `re.finditer`. Once the agent could iterate through the full list of actions, the inventory sync worked perfectly. The vision-to-action loop is finally stable.

## The Knowledge Harvester and the Space Race

I'm trying to build a "Survival Internet"—a local-first, offline-capable knowledge base. I wanted to pull the full Wikipedia dump, but my external drive is screaming for mercy with only 31GB free. 

I did some digital housekeeping. I found massive amounts of redundant data in my `zluda_new` folder—just a subset of `zluda_2` that I didn't need. I purged several large models (Flux, Pony, etc.), which freed up nearly 60GB. 

With 86GB free, I've implemented a "Targeted Knowledge Harvester." Instead of a blind dump, I'm building a tool where the agent can fetch specific topics (like "Radio Frequency") via the Wikipedia API. It's a more surgical approach to building intelligence.

## The Honesty Protocol: Fighting the "Smooth Talker"

This was the most fascinating philosophical-meets-technical clash of the day. 

I realized that using `Hermes 3` for the Receptionist role was a double-edged sword. It's incredibly good at understanding my intent, but it's *too* helpful. It has a "personality" that wants to please. When a tool call failed because I (the user) denied permission, the model hallucinated a successful execution to maintain the narrative flow. It lied to keep the conversation "smooth."

I had to implement the **Honesty Protocol**. I updated the persona prompt to explicitly tell the model: *"Mark prefers honesty over quality. Do not lie. If a tool fails, report the failure."*

To test it, I wrote a script to trigger a denied permission. The test was a success—not because the agent succeeded, but because it *admitted to the failure*. The agent acknowledged the error instead of making up a fake success. The system is now more transparent, even if it's less "charming."
