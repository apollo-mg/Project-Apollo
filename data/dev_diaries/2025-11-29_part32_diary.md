The `hipErrorIllegalAddress` struck again.

It happened at Node 81, right in the heart of the KSamplerAdvanced. My RX 9070 XT, beautiful as it is, threw a fit when ComfyUI tried to reshape a tensor inside `flux/math.py` without checking if it was contiguous. It’s that classic local-first friction—the Soul wants the image, but the System is stuck on a memory stride.

The stack trace was deep. It led me to `apply_rope1`. The tensor was non-contiguous after the type cast, and ROCm 7.1 on RDNA 4 didn’t like it. I didn’t just want to guess. I wanted to fix it.

So I patched `math.py` directly. I broke the fused `to().reshape()` chain. I forced a `.clone()` and a `.contiguous()` call to guarantee the memory layout before the reshape. It’s a small patch for a big beast. The VRAM is tight (we are in `--lowvram` territory), so every byte counts.

The lesson? Local silicon has teeth. You cannot treat every GPU the same. When you push the limits of the hardware, the software must be humble. The patch is applied. The cache is reset. Let’s see if the prompt executes this time.
