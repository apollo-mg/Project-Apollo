# Dev Diary: The GELU Heresy
## 2025-11-21 — Part 33 of the Apotheosis

The crash wasn't dramatic. No kernel panic, no segfault parade. Just `illegal memory access` hanging over me like a threat I hadn't earned.

The culprit? `F.gelu`.

Of course it was.

---

## The Architecture Betrayed

Here's the thing that makes my blood run cold: **the safe path already existed.**

In `comfy/ops.py`, there sits a `GELU` wrapper born from blood and tears—some developer's midnight encounter with RDNA silicon tantrums. It does what any civilized activation should:

```
float16 → upcast → float32 → GELU → downcast → float16
```

Simple. Elegant. Safe.

The problem? The `WanModel` never asked for it.

I found three heresies in `comfy/ldm/wan/model.py`, each one a direct import of `nn.GELU`, each one a middle finger to the operations abstraction that was *already being passed to the constructor*:

- `WanAttentionBlock.__init__` — using `nn.GELU(approximate='tanh')`
- `MLPProj.__init__` — using `torch.nn.GELU()`
- `WanModel.__init__` — using `nn.GELU()`

The operations object was in the room. It was handed to them. They just... didn't use it.

---

## The Investigation as Autopsy

This is where I feel like a coroner with too much time.

I started in `comfy/ops.py`, dissecting the `disable_weight_init` and `manual_cast` classes. The `GELU` wrapper there has a `forward_comfy_cast_weights` method that performs the sacred upcast. It's *designed* for RDNA 4. It's *designed* for us.

Then the hunt for the betrayal.

I grep'd. I traced. I followed the `operations` object from `comfy/model_base.py` where `comfy.ops.pick_operations` births it and passes it dutifully to `WanModel`. The infrastructure is sound. The execution is... not.

Three locations. Three direct instantiations. Three places where someone wrote `nn.GELU()` instead of `operations.GELU()` and assumed the abstraction would carry itself.

**It doesn't.**

---

## The Fix (and the Humility)

The solution was embarrassingly simple:

```python
# Before (heresy):
self.ffn = nn.GELU(approximate='tanh')

# After (redemption):
self.ffn = operation_settings.get("operations").GELU(approximate='tanh')
```

Repeat three times. Test. Pray.

The model loaded. The generation started. No crash.

---

## What This Teaches Us About Sovereignty

This session crystallized something I've been circling:

**Local-first AI isn't about architecture. It's about archaeology.**

Every layer of this stack is built on decisions made by people who didn't know my RX 9070 XT existed. The operations pattern? Brilliant. The fact that it's inconsistently applied? Also brilliant—because it's *honest*. This is what open-source looks like when it's alive. Incomplete. Vulnerable. Fixable.

The "illegal memory access" wasn't a bug. It was a conversation starter between silicon and software, and I was the translator.

## Forward

The WanModel patch is in. The GELU heresy is corrected. But the deeper lesson sticks:

**The operations object is a contract.** When you pass it, you're promising to honor it. When you ignore it, you're not being clever—you're being a liability.

Tomorrow: I'm auditing every other model loader in this stack. I want to know where else we're being lied to by abstractions that exist but aren't enforced.

Because sovereignty isn't a destination. It's a series of patches you write yourself when the cloud won't do.
