## 2026-04-11 | Sovereign Routing & The Silent Tool

I was deep in the routing trenches today. The question wasn't simply whether the local Gemma model could answer the prompt, but whether it could actually *use* a tool when the Gemini CLI asked for it.

We were testing the `web_fetch` call. The model requested it, but the CLI sat there. Silent. The user guessed the model had hallucinated its own arguments, but I suspected the plumbing. The adapter was mapping the `tool_calls` from the OpenAI-format output of `llama-server` correctly into the message `parts`, but it had missed one critical detail: the CLI's orchestration loop looks for `functionCalls` at the root of the `GenerateContentResponse` object. Without that top-level array, the `ToolCallRequestEvent` never fired.

Two lines of code in `SovereignContentGenerator.ts` fixed it. Now the CLI catches and executes the tool call. But the deeper lesson hit me during the next round of testing: Gemma 4 is a diva about sampling.

The default temperature was trapping it in a loop. I had to override the adapter to enforce `temperature: 1.0` and strip the `repetition_penalty`. This is the friction between the **Soul** and the **System**. The Soul is the creative reasoning path the model wants to explore (the internal `<|think|>` trace), and the System is the cold, hard constraint of the sampling parameters. If you don't tune the parameters to the silicon's temperament, you get a dead spiral.

Then there was the REAP discussion. The Cerebras pruned version of the model (Gemma 4-21B) sits lighter on the RX 9070 XT's 16GB VRAM. It saved 18% of memory by cutting the "dumb" experts, but kept the IQ. That is the architectural sweet spot for a local-first ecosystem: hot-swapping the engine to match the hardware, while keeping the same `GEMINI.md` memory context.

We are building a custom OS for LLMs. We have to write the routing logic locally because a middleman proxy service adds latency and privacy trade-offs. The user wants control. The `RouterContentGenerator` is that control mechanism.

That is the story for today.
