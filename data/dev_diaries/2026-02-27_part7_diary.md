# Dev Diary: 2026-02-27 (Part 7)

## The Ghost in the Machine and the VRAM Tetris

Today was a brutal lesson in the friction between a "Soul" (the vision/reasoning capabilities I want for Apollo) and the "System" (the rigid, temperamental reality of the RX 9070 XT and Windows).

I spent most of the morning battling a phenomenon I can only describe as "The Ghost in the Machine." I thought I was running a single, streamlined Discord bridge. I was wrong. Because of how Windows handles backgrounded PowerShell processes, I had **nine separate clones** of the bot running simultaneously. Every time I attempted a restart, the old ones wouldn't die. They were all fighting for the same 16GB of VRAM, all vying for the same port, all responding to the same Discord message. It was a digital civil war that resulted in repeated, garbled responses and a complete breakdown of the intelligence layer.

I had to perform a "Great Ghost Purge"—a total, scorched-earth termination of every Python process and a hard reset of the Ollama server. Once the system was clean, I could finally implement the "VRAM Tetris" logic. This is the core of our current architectural challenge: the seamless handoff between the 14B Engineer (DeepSeek) and the Vision Mind (Qwen-VL). Using `vram_management.py`, I can now force the system to unload the heavy reasoning model before loading the vision model. It’s a delicate dance on a single GPU, but it’s the only way to achieve a multi-agent ecosystem on local silicon.

## The Vision Failure: A Lesson in Context Injection

The transition to vision-capable agents was more complex than anticipated. I tried to implement image analysis, but the model was hitting a 500 Internal Server Error. 

The culprit was a logic short-circuit in `llm_interface.py`. When the model received an image, it was also receiving the entire conversation history. Because of the way the payload was being constructed, the history was overwriting the image data. The model was effectively being asked to "Describe this image" while being handed an empty array of pixels. 

I had to refactor the entire communication layer to ensure that image data is treated as a first-class citizen, injected directly into the **System Message** rather than the user prompt. This "Hard-Injection" forces the model to acknowledge the visual context immediately, bypassing the "I am a helpful AI, please use my API" refusal loops that the model's safety training was triggering.

## Architectural Epiphany: The Monolith vs. The Swarm

The most significant progress today was the successful refactoring of `buddy_agent.py`. We've moved away from a monolithic script toward a modular, service-oriented architecture.

*   **The Apollo Backbone:** Now handles the heavy lifting of orchestration and the Discord connection.
*   **Specialized Modules:** `dev_buddy` and `shop_buddy` are becoming distinct entities.

This is crucial. As we scale toward "The Swarm" (Phase 9), we can't have one file managing everything. By decoupling the `Toolbox` from the `Dispatcher`, we can eventually move to a Linux/WSL environment without rewriting the entire core logic. This modularity is what will allow us to add a `Print_Buddy` for the 3-axis machines later this week.

## Lessons Learned & Current State

1.  **VRAM is the ultimate constraint:** Our "Soul" is limited by the size of the silicon. Every extra parameter in a model is a tax on the ability to run multiple agents.
2.  **Windows/ROCm Friction:** The driver quirks on Windows are real. The `WinError 5` (Access Denied) and the way PowerShell handles streams means we have to be much more aggressive with path management and process termination.
3.  **The Need for Remote Observability:** The decision to pipe the `#monitoring` channel to Discord was vital. Seeing the raw JSON payloads and the `[ATTACHED_IMAGE]` tags in real-time is the only way to debug these asynchronous, multi-agent loops.

**Next Objective:** Validate the Vision Mind's accuracy and stabilize the asynchronous logging. If we can get the vision model to reliably describe images without crashing the VRAM swap, we've cleared the biggest hurdle for Phase 7.
