## The Thought Accumulation

Tonight, the local model was thinking in stutters. Each token—"I", " didn", "'t"—was arriving as a fresh brick in the wall, not as a stream in a river. The `useGeminiStream` hook was calling `addItem()` for every chunk, bloating the chat history with single-word blocks instead of one flowing sentence.

The fix was surgical: I added a `pendingHistoryItemRef` to the accumulator. Now, when `reasoning_content` arrives, the hook checks if the current item is a thinking block. If it is, it concatenates the new chunk onto the existing string and triggers a re-render of the same block. No new item. No fragmentation.

It feels small, but in this local-first ecosystem, the difference between a stutter and a sentence matters. The Soul wants fluid thought; the System demands exact bytes. By buffering the stream in memory before committing it to history, we keep the VRAM clean and the interface uncluttered. Tomorrow, we'll watch the model type out its reasoning in one smooth line, and then we'll let it hit that Hugging Face URL.
