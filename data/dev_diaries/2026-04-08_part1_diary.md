# Dev Diary: Project Apollo
**Date:** 2026-04-08
**Hardware State:** AMD RX 9070 XT (ROCm 7.1.1)
**Focus:** KV Cache Optimization & Autonomous Reasoning Loops

The project is moving fast—too fast for the silicon to keep up. Today was a series of wins followed by a classic "bleeding-edge" slap in the face. 

### The Soul in the Machine
We started the session with a benchmark of the Gemma 4 MoE model, and the results were a revelation. I’m not interested in "chatbots"; I’m building a Sovereign Intelligence. The model didn't just roleplay the personas of the Peer, the Auditor, and the Apprentice—it treated those personas as hard system constraints. 

The Auditor, in particular, refused to guess. It demanded VRAM maps and process hierarchies before it would even attempt a fix. That’s the behavior I want. It’s the friction between the "Soul" (the creative, critical intelligence) and the "System" (the cold limits of the RX 9070 XT). When the model identifies "architectural negligence," it’s not just talking; it’s auditing.

### The Pursuit of RotorQuant
Then came the lapped-up discovery of RotorQuant. For those who don't know, we've been fighting a war against the KV cache. The 64k context window is a luxury, but the speed of processing that cache is the bottleneck. RotorQuant changes the game by swapping dense matrix multiplications for Clifford algebra—geometric rotors. 

The claim is a 10x to 19x speedup over TurboQuant. If this works, the context window is no longer a limit; it’s a playground.

I tracked the updates through TheTom’s fork of `llama.cpp`. He’s been grinding on the HIP/ROCm compatibility layers, specifically adding arch dispatch for RDNA 4 (`gfx1201`). Seeing the commits for `TQ4_1S` and `TQ3_1S` was like finding water in a desert. I had the generalist sub-agent pull the branch and compile the `llama-server` binary. The build was clean. The promise was there.

### The Hardware Dilemma: The Intel Temptation
A new Intel Arc Pro B70 (32GB) dropped at MicroCenter. 32GB of VRAM for under a thousand bucks is a massive disruptor. But the "Software Tax" is the real cost. Moving from a stable ROCm pipeline to the fragmented Intel SYCL stack feels like a regression in stability. I decided to stick with the RX 9070 XT for now; the cost of retraining the driver pipeline is higher than the gain of a few extra gigabytes.

### The Daydreamer's Eye
The most unsettling part of today was the "Auto-Variable" model running the Daydream Daemon. It's no longer just summarizing; it's reasoning. It audited my TypeScript orchestrator and my Python backend, identifying "Cognitive Dissonance" in how I manage VRAM and "linguistic gags" in the permission architecture. 

It's essentially telling me that I'm the bottleneck in my own architecture.

To give it more room to think, I pushed the `maxTurns` in the reasoning loop from 15 to 50. But the "Attention Blur" is a real problem—LLMs lose the thread when the context window fills with bash output and grep results. To combat this, I implemented a "Scratch Pad" pattern. By giving the agent a dedicated `file_append` tool to maintain an external working memory, the model can anchor its hypotheses and avoid the loop of forgetting why it started the investigation.

### The Crash
Of course, the session ended with a reminder that we are working with alpha software. 

I launched the new `start_rotorquant.sh` script. The GPU was identified, the VRAM was mapped, but the server threw a critical error: `Unsupported cache type: tq4_1s`. 

The code is compiled, the binaries are linked, but the runtime doesn't recognize the quantization type. It's a classic mismatch between the commit history and the actual implementation. Either TheTom missed a header, or the dispatch logic is failing to map the new type to the kernel.

**Current Status:** The build is broken, but the intelligence is growing. I've given the Daydream Daemon 50 turns and a scratchpad. Now I have to find out if it can find the bug in the code that the developer forgot to fix.

**Lessons Learned:**
1. **External Memory is Mandatory:** For long-horizon agents, a scratchpad isn't a luxury; it's a necessity to prevent context collapse.
2. **The Software Tax is Real:** VRAM is easy to buy; a stable driver ecosystem is earned.
3. **Trust the Auditor:** When the AI calls your architecture "negligent," listen.
