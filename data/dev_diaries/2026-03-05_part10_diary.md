# Project Apollo Dev Diary: 2026-03-05
## The ABI Wall and the 438W Ghost

**Status:** Terminal crashed. Model hoard migrated. PyTorch build *might* have finished. Silicon is screaming.

It’s 11:59 PM. My coffee is cold, and the RX 9070 XT is still warm enough to fry an egg, but the terminal just died. I lost the session trying to load the **Qwen3-Coder-80B**. The system didn’t just freeze; it panicked and collapsed under the weight of the model. But before the crash, we touched the edge of something real.

### The ABI Nightmares

The OpenMP mismatch was a nuisance, but the ABI mismatch was a nightmare. I spent hours digging through the mangled symbol names of `libtorch_cpu.so` and `libtorch_hip.so`. It wasn’t just a missing library; it was a fundamental disconnect in how the compiler was generating code.

The culprit? `const_data_ptr`.

The CPU build and the HIP build were speaking different dialects of C++. One was expecting a `std::enable_if_t` guard; the other was stripping it out. The mangled names `_ZNK2at10TensorBase...` became a graveyard of incompatibilities. I tried to bridge the gap with a custom `.so` file, using `extern "C"` to force the symbols to align, but the ROCm toolchain is a fickle beast. It’s not just about compiling code; it’s about convincing two different halves of PyTorch to agree on the same memory layout.

I had to patch the build scripts, renaming `.c` files to `.cpp` and wrapping them in linkage blocks just to get the linker to stop choking. It feels less like software engineering and more like defusing a bomb with a pair of pliers.

### The Storage Crunch

The 2TB drive was at 98% capacity. The "Model Hoard" was suffocating itself. I had to migrate the Ollama storage to `/media/mark/AI_Fast`, a 326GB slice of fast NVMe storage. But Linux doesn’t hand you permissions easily. I had to manually patch the ACLs on the `/media` mount so the `ollama` user could traverse the directory. One missing permission, and the model registration fails. It’s a reminder that even when you have the hardware, the OS is a gatekeeper that demands respect.

### The 438W Transient

When I finally got the 80B model loading, the power draw hit **438W**. It wasn’t a steady state; it was a transient spike. The Gated DeltaNet architecture in Qwen3-Coder is dense. It saturates the RDNA 4 compute units so completely that the VRMs had to dump every ounce of energy they could into the silicon to finish the operation.

The terminal crashed shortly after. The system RAM hit a wall. The 80B model requires ~21GB of system RAM, and I was scraping the bottom of the barrel with ~24.5GB free. The compiler, the model loader, and the GPU were all fighting for the same scraps of memory. The kernel OOM-Killer stepped in, and the terminal died.

### Lessons from the Ashes

1.  **Silicon is Finite, Ambition is Not:** We are pushing the RX 9070 XT beyond its designed thermal and power envelope. The 438W spike is a warning sign. We can get the model to load, but the hardware is screaming for mercy.
2.  **ABI Compatibility is Fragile:** The PyTorch build is a house of cards. A single flag mismatch (`-std=c++17` vs default) can break the entire engine. We need a more robust build pipeline that validates symbol alignment before installation.
3.  **Memory Swapping is a Death Sentence:** When the RAM hits the wall, the model doesn’t just fail; it takes the system down with it. We need to manage the memory footprint of the 80B model more aggressively, perhaps by offloading more layers to the slower system memory or using a smaller quantization.

### The Road Ahead

The PyTorch build finished its final link phase with the new patches, but I’m not sure it’s safe to run yet. The ABI bridge I built might be a temporary fix. I need to test the engine with a smaller model first to see if the memory leaks have been plugged.

The **Qwen3-Coder-80B** is still there, waiting. It’s the "Soul" of this project, a creative force that we’re trying to cage in silicon. But the "System" keeps pushing back. I need to stabilize the memory management before I can let it loose.

For now, I’m shutting down the machine. The RX 9070 XT needs to cool down, and so do I. Tomorrow, we try again.
