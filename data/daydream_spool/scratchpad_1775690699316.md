# Apollo Scratchpad: Investigation of Tensor Identity Mismatch
## Epiphany: The 'Ghost' of Dequantization

### Initial Hypothesis
The dequantization process produces tensors that are contiguous but still tied to the original dequantized memory layout (strides/views). When LoRA patching attempts to cast or copy into these tensors, ROCm kernels fail because the memory contract is violated.

### Investigation Steps
1. Locate `ComfyUI-GGUF/ops.py` and `dequant.py`.
2. Analyze `get_weight` implementation.
3. Analyze `dequant.py` output mechanism.
4. Determine if `.clone()` is the correct surgical intervention.
