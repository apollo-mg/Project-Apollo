# Architectural Proposal: State Handover Protocol (Phase 5 -> Phase 6)

## 1. Problem Statement
The current transition from Phase 5 (Strategic Planning/Management) to Phase 6 (The Architect) suffers from a "verification loop." The Architect is forced to re-parse extensive operational histories and perform broad semantic searches across Tier 2 and Tier 3 memory to reconstruct the strategic intent of the previous phase. This creates unnecessary cognitive load and latency.

## 2. Proposed Solution: Compressed Context Seed
Implement a 'State Handover' protocol that generates a highly distilled, semantic summary of the strategic state. This "Compressed Context Seed" acts as a bridge, allowing the Architect to inherit intent without historical re-parsing.

## 3. Technical Specification

### 3.1. New Data Structure: `HandoverSeed`
A new dataclass will be introduced in `src/modules/memory_system.py` to encapsulate the distilled state.

```python
@dataclass
class HandoverSeed:
    seed_id: str
    strategic_intent: str  # High-level summary of goals
    operational_constraints: List[str]  # Key rules/limitations
    completed_milestones: List[str]  # What is already 'done'
    pending_objectives: List[str]  # Immediate next steps for the Architect
    context_snapshot_hash: str  # Integrity check for the seed
    timestamp: float
```

### 3.2. Protocol Workflow
1. **Generation (Phase 5):** Upon completion of strategic planning, the `TieredMemorySystem` (or a specialized `HandoverManager`) will perform a "Distillation Pass." It will query Tier 2/3 for recent high-importance entries and use a lightweight model to synthesize the `HandoverSeed`.
2. **Injection (Phase 6):** When the `Agent` is initialized for the Architect role, the `HandoverSeed` is injected directly into the `Tier1WorkingBuffer`.
3. **Execution:** The Architect begins its lifecycle with the `HandoverSeed` as its primary context, effectively "waking up" with the strategic intent already loaded.

## 4. Implementation Plan

### Step 1: Update `src/modules/memory_system.py`
- Add `HandoverSeed` dataclass.
- Add `generate_handover_seed(self, context_window: int) -> HandoverSeed` to `TieredMemorySystem`. This method will summarize recent Tier 2 entries.

### Step 2: Update `src/agent/agent.py`
- Modify `Agent.__init__` to accept an optional `handover_seed: Optional[HandoverSeed]`.
- If provided, the `Agent` will automatically populate its `Tier1WorkingBuffer` with the seed's contents.

### Step 3: Integration in Orchestration
- Update the system's main loop (likely in `orchestrator.py` or `task_manager.py`) to trigger the seed generation during the phase transition.

## 5. Expected Impact
- **Reduced Latency:** Eliminates the need for the Architect to perform initial "discovery" searches.
- **Improved Intent Alignment:** Reduces the risk of the Architect drifting from the strategic goals established in Phase 5.
- **Cognitive Efficiency:** Breaks the recursive verification cycle by providing a "ground truth" starting point.
