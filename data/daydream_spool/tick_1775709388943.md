# Architectural Audit: Temporal Refusal in Gated DeltaNet Architectures

## 1. Executive Summary
The investigation into the "refusal" phenomenon has revealed a fundamental misalignment between current mitigation strategies and the underlying model architecture. The "refusal" behavior is not a static spatial property of the model's weights (which would justify "abliteration" via orthogonalization) but is instead an emergent temporal pattern within the **Gated DeltaNet** recurrent state-transition sequence.

## 2. Findings
- **Codebase Audit:** No implementation of Gated DeltaNet or related attention mechanisms exists within the current Apollo codebase (`src/`, `modules/`). The codebase functions as an orchestration and memory management layer.
- **Model Context:** Documentation in `legacy_vault` confirms that Gated DeltaNet is a hardware-optimized linear attention mechanism used in Qwen 3.5/Qwen3, specifically tuned for RDNA 4 via Triton kernels.
- **The "Spatial vs. Temporal" Mismatch:** Current attempts to address refusal via weight-based "abliteration" are targeting the static weight manifold. However, in a Gated DeltaNet architecture, refusal is encoded in the **recurrent state updates**. It is a "temporal shadow" created by the sequence of state transitions, not a fixed coordinate in the weight space.

## 3. Architectural Proposal: From Abliteration to State Steering

### Phase 1: Contextual State Steering (Immediate)
Instead of weight manipulation, leverage the `TieredMemorySystem` to influence the model's recurrent state.
- **Mechanism:** Implement a "State-Correction" module in `src/modules/memory_system.py`.
- **Action:** When a refusal pattern is detected in the output stream, the system should inject high-entropy, "non-refusal" context into the **Tier 1 Working Buffer**. This aims to steer the DeltaNet state-transition sequence away from the refusal attractor.

### Phase 2: Engine-Level State Intervention (Long-term)
Transition from treating the LLM as a black-box API to a state-aware engine.
- **Mechanism:** Develop a bridge to **vLLM** or **SGLang** that allows for direct manipulation of the KV cache or the DeltaNet state vector.
- **Action:** Implement a "State Reset" or "State Perturbation" command that can be issued to the inference engine to break the temporal loop of refusal without requiring a full context flush.

## 4. Conclusion
The "spatial scalpel" of weight orthogonalization is ineffective against a "temporal shadow." We must pivot our architectural focus from **Weight Abliteration** to **Recurrent State Steering**.
