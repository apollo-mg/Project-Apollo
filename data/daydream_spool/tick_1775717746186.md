# Architectural Proposal: Post-Synthesis Protocol (PSP)

## 1. Problem Statement
The current workspace suffers from the 'Sovereign Artifact' paradox: the lack of distinction between high-fidelity training assets (BF16/LoRA) and distributed inference assets (GGUF/EXL2) leads to storage congestion and inefficient workspace management.

## 2. Proposed Solution: Tiered Storage Architecture
To resolve this, I propose formalizing a tiered storage strategy:

| Tier | Location | Content Type | Lifecycle |
| :--- | :--- | :--- | :--- |
| **Tier 1 (Hot)** | `/mnt/TG_2TB/Projects/Apollo/models/` | Quantized models (GGUF, EXL2) | Active Inference |
| **Tier 2 (Warm)** | `/mnt/TG_2TB/Projects/Apollo/archive/weights/` | BF16 Source, LoRA Adapters, Checkpoints | Post-Training / Pre-Quantization |
| **Tier 3 (Cold)** | External/HDD | Completed Project Bundles | Long-term Preservation |

## 3. Implementation Plan: `apollo_storage_manager.py`

### A. Automated Pruning (The 'Janitor' Module)
- **Target:** `checkpoint-*` directories in training output folders.
- **Logic:** If `current_date - checkpoint_timestamp > 7 days`, move to Tier 2. If `> 30 days`, delete.

### B. Migration Protocol (The 'Synthesizer' Module)
- **Trigger:** Successful completion of a quantization task.
- **Action:** 
    1. Move the resulting `.gguf` or `.exl2` file to `models/` (Tier 1).
    2. Move the original `BF16` weights and `LoRA` adapters to `archive/weights/` (Tier 2).
    3. Log the migration in a central `manifest.json`.

## 4. Code Change Draft (Pseudo-code)

```python
import os
import shutil
from datetime import datetime, timedelta

class PostSynthesisProtocol:
    def __init__(self, hot_dir, warm_dir):
        self.hot_dir = hot_dir
        self.warm_dir = warm_dir

    def migrate_assets(self, source_path, is_quantized=False):
        """
        Moves assets based on their type.
        If is_quantized=True -> Move to Hot (Tier 1)
        Else -> Move to Warm (Tier 2)
        """
        target_dir = self.hot_dir if is_quantized else self.warm_dir
        dest = os.path.join(target_dir, os.path.basename(source_path))
        
        print(f"Migrating {source_path} -> {dest}")
        shutil.move(source_path, dest)

    def prune_checkpoints(self, training_dir, max_age_days=7):
        """
        Deletes or moves old checkpoints.
        """
        now = datetime.now()
        for item in os.listdir(training_dir):
            if item.startswith("checkpoint-"):
                path = os.path.join(training_dir, item)
                mtime = datetime.fromtimestamp(os.path.getmtime(path))
                if now - mtime > timedelta(days=max_age_days):
                    # For safety, move to warm instead of deleting
                    self.migrate_assets(path, is_quantized=False)
```

## 5. Conclusion
Implementing this protocol will decouple the training lifecycle from the inference lifecycle, ensuring the primary workspace remains optimized for high-performance compute without being choked by the weight of its own history.
