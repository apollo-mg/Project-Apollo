# Apollo Investigation: Hardware Profile System vs. Core Patching

## Objective
Investigate the current method of handling VRAM bottlenecks and identify instances of "patching" core files to resolve memory issues. Evaluate the feasibility of a standardized 'Hardware Profile' system.

## Initial Hypotheses
1. The system currently uses conditional logic or monkey-patching within core nodes to adjust tiling/decoding based on VRAM.
2. This approach creates friction because it's opaque to the user and hard to override.
3. A profile-based injection system would decouple hardware optimization from core logic.
