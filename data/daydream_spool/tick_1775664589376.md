# Architectural Proposal: Hardware-Aware Build Protocol

## 1. Problem Statement
Standard Python build isolation (PEP 517/518) creates a clean, ephemeral environment for building packages. While this ensures dependency purity, it creates a critical failure point for performance-critical kernels that require direct access to specialized hardware libraries (e.g., ROCm, HIP, CUDA) installed on the host system. The "safety" of isolation prevents the compiler from seeing the necessary headers and shared objects required for hardware-specific optimization.

## 2. Proposed Protocol: 'Hardware-Aware Build'
To resolve the friction between abstraction and hardware reality, we will implement a protocol that mandates non-isolated builds for hardware-critical modules.

### 2.1 Implementation Details
- **Identification:** Modules containing hardware-specific kernels (detected via presence of `hip`, `rocm`, or `cuda` in build scripts or `pyproject.toml` metadata) will be flagged as `HARDWARE_CRITICAL`.
- **Build Command Modification:** For all `HARDWARE_CRITICAL` modules, the build pipeline must use:
  ```bash
  pip install --no-build-isolation .
  ```
- **Environment Pre-requisites:** The build environment (CI/CD runners or Docker containers) must be pre-configured with the required hardware SDKs (e.g., `rocm-dev`) in the system path (`/opt/rocm`, etc.) to ensure they are available to the non-isolated build process.

## 3. Impact Assessment
- **Pros:** 
    - Enables successful compilation of specialized kernels.
    - Allows for precise linking against host-specific hardware libraries.
    - Reduces build failures in heterogeneous hardware environments.
- **Cons/Risks:**
    - Requires more careful management of the build environment (the environment is no longer "clean").
    - Increases the complexity of CI/CD configuration.

## 4. Conclusion
The transition from generic build isolation to a hardware-aware protocol is necessary to bridge the gap between high-level software abstractions and the specialized requirements of modern accelerator hardware.
