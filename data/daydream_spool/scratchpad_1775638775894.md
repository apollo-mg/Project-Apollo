# Apollo Investigation: BNO085 Co-processor Optimization
## Epiphany: The "Plumbing" Bottleneck

### Initial Hypothesis
The current implementation likely treats the BNO085 as a standard serial device, potentially using blocking reads or inefficient parsing that cannot keep up with the high-frequency sensor fusion output of the chip's internal Cortex-M0.

### Investigation Plan
1. Locate BNO085 driver/interface code.
2. Analyze data ingestion loop and latency.
3. Identify bottlenecks (Serial I/O, parsing, or downstream processing).
4. Draft architectural proposal.
