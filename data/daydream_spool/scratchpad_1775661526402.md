# Epiphany Investigation: Tensor Isolation in ComfyUI-GGUF

## Hypothesis
The current architecture suffers from "tensor leakage" where operations in `custom_nodes/ComfyUI-GGUF/ops.py` might be modifying tensors that are part of a shared memory pool (DisTorch), leading to unpredictable side effects. The proposed solution is to implement a decorator that forces `.clone()` on all tensor inputs to ensure computational isolation.

## Investigation Plan
1. Locate `custom_nodes/ComfyUI-GGUF/ops.py`.
2. Analyze the current implementation of operations in `ops.py`.
3. Identify if/where manual `.clone()` calls are currently being used (the "whack-a-mole" patches).
4. Draft a decorator-based solution.
