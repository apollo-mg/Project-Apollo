# Architectural Audit & Proposal: Dynamic Ambient Noise Profiling

## 1. Executive Summary
The current audio ingestion pipeline in `wake_up.py` relies on static Voice Activity Detection (VAD) parameters and hard-coded silence thresholds. This creates a "mathematical cage" that fails to adapt to environmental changes (e.g., AC hum, fan noise, or shifting ambient levels). The system treats noise as an outlier to be suppressed rather than a baseline to be understood.

## 2. Identified Vulnerabilities
- **Static VAD Mode:** `webrtcvad.set_mode(3)` is used as a "one-size-fits-all" solution. While aggressive, it lacks context regarding the current signal-to-noise ratio (SNR).
- **Fixed Silence Threshold:** The `max_silence_chunks` is hard-coded to 1.5 seconds. In high-noise environments, the system may struggle to distinguish between a user's pause and ambient noise spikes, leading to fragmented or failed transcriptions.
- **Lack of Environmental Awareness:** There is no mechanism to differentiate between a "quiet room" and a "noisy room," making the system brittle to environmental shifts.

## 3. Proposed Architectural Update: `AmbientNoiseDaemon`

### A. Concept
Transition from **Static Suppression** to **Dynamic Baseline Tracking**. We will implement a background profiling mechanism that treats the ambient noise as a constant, measurable baseline.

### B. Component Specifications

#### `modules/noise_profiler.py` (New Module)
- **Function:** Continuously monitors the audio stream during non-speech intervals.
- **Logic:** 
    - Calculates the RMS (Root Mean Square) amplitude of audio chunks.
    - Maintains a `MovingAverageNoiseFloor` using an Exponentially Weighted Moving Average (EWMA) to prevent sudden spikes from corrupting the baseline.
    - Provides a `get_current_threshold()` method that returns `noise_floor + dynamic_margin`.

#### `wake_up.py` (Refactor)
- **Integration:** Initialize the `NoiseProfiler` alongside the `webrtcvad` instance.
- **Hybrid Detection Logic:**
    - Instead of relying solely on `vad.is_speech()`, the system will use a hybrid check:
      `is_speech = (vad.is_speech(data, RATE) OR current_rms > noise_profiler.get_threshold())`
- **Adaptive Silence Detection:**
    - The `silence_chunks` counter will be modulated by the noise floor. If the noise floor is high, the required "silence" duration to trigger a cut-off will be dynamically extended to prevent premature termination of speech.

### C. Implementation Roadmap
1. **Phase 1 (Profiling):** Implement `noise_profiler.py` and integrate it into the `wake_up.py` loop in a "monitor-only" mode to collect baseline data.
2. **Phase 2 (Hybrid Logic):** Implement the hybrid VAD/RMS check.
3. **Phase 3 (Adaptive Silence):** Implement the dynamic silence duration based on the noise floor.

## 4. Conclusion
By treating the environment as a baseline rather than an enemy, the Sovereign Audio Stack will achieve significantly higher robustness in real-world, non-studio environments. This shift moves the system from a "rigid cage" to an "adaptive listener."
