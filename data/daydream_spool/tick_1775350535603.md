# Architectural Audit: Cognitive Escalation Protocol

## Epiphany Summary
The subconscious identified a critical failure mode: standard coding models (fast-path) are insufficient when abstraction layers collapse (Python -> Torch -> HIP -> Hardware). A "Cognitive Escalation" protocol is required to trigger "Deep Reasoning" (e.g., DeepSeek-R1) when system-level or hardware-level exceptions occur.

## Current State Analysis
The current `ApolloAgentSession.run` loop (in `modules/agent_session.py`) handles tool execution errors via a generic `except Exception as e` block (lines 185-188). 

```python
185	                except Exception as e:
186	                    stylized_print("error", f"Tool Execution Error: {e}", color=CLR_GOLD)
187	                    self.messages.append({"role": "user", "content": f"TOOL EXECUTION FAILED: {e}."})
188	                    any_called = True 
```

This implementation:
1.  Treats all errors identically.
2.  Feeds the error back to the *current* model (which is likely the same "fast" model that failed).
3.  Does not distinguish between a syntax error (fixable by the current model) and a hardware/driver error (requiring architectural reasoning).

## Proposed Architectural Update: Cognitive Escalation

### 1. Error Classification Logic
We must implement a classifier to distinguish between `RECOVERABLE_LOGIC_ERROR` and `CRITICAL_SYSTEM_ERROR`.

**Critical System Error Patterns:**
- `torch.cuda.OutOfMemoryError` / `torch.cuda.Error`
- `RuntimeError: HIP error` / `HIP error`
- `Segmentation Fault`
- `Memory Access Violation`
- `AcceleratorError`

### 2. Implementation Plan

#### Step A: Define Error Categories
Create a utility in `modules/toolbox.py` or a new `modules/error_classifier.py` to identify high-level system failures.

#### Step B: Modify `ApolloAgentSession.run`
Update the `except` block in `modules/agent_session.py` to implement the escalation:

1.  **Catch Exception:** Intercept the error.
2.  **Classify:** Check if the error string matches "Critical System" patterns.
3.  **Escalate:** If critical, instead of just appending the error to `self.messages`, trigger a specialized `llm_interface.deep_reasoning_session(error_context)`.
4.  **Inject Reasoning:** The output of the Deep Reasoning session (the diagnosis) is then injected into the agent's context as a high-priority system message, allowing the agent to pivot its strategy.

## Conclusion
The "Cognitive Escalation" protocol transforms Apollo from a reactive loop into a proactive, multi-tiered intelligence system. It ensures that when the hardware layer fails, the software layer doesn't just "loop" on the error, but "thinks" through the abstraction collapse.
