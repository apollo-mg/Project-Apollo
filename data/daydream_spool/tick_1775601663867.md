# Architectural Audit: Financial Circuit Breaker Implementation

## Epiphany Analysis
The subconscious has identified a critical structural vulnerability: the absence of a programmatic fiscal governor. Current "crisis management" (manual API disabling) is reactive and insufficient. The system requires an autonomous **Financial Circuit Breaker** to bound generative growth within fiscal constraints.

## Audit Findings
1.  **Current State:** The codebase lacks any mechanism for real-time expenditure monitoring or automated service suspension based on cost.
2.  **Token Tracking:** The `LLMResponse` type (in `src/types.ts`) and `AgentRunResult` already track `TokenUsage`. However, this is currently used only for local agent state and is not aggregated or monitored against a global budget.
3.  **Control Plane:** There is no centralized "Governor" or "Circuit Breaker" service that can intercept LLM calls or abort agent runs based on external fiscal telemetry.
4.  **Enforcement Mechanism:** The `AgentRunner` uses `AbortSignal` to stop loops. This is the ideal mechanism for the Circuit Breaker to use to "kill" runaway processes.

## Proposed Architectural Update: The 'Metabolic Regulator'

### 1. New Module: `src/orchestrator/governor.ts`
Implement a `FiscalGovernor` singleton that:
- Maintains a real-time registry of cumulative token usage/cost across all active `AgentRunner` instances.
- Accepts a `BudgetConfig` (e.g., `max_usd_per_hour`, `max_tokens_per_session`).
- Provides a `checkThreshold()` method called during the `AgentRunner` loop.

### 2. Integration: `src/agent/runner.ts`
Modify the `AgentRunner.stream` loop to integrate with the `FiscalGovernor`:
- **Before each LLM call:** The runner must query the `FiscalGovernor`.
- **If threshold breached:** The `FiscalGovernor` will trigger an `AbortController` signal, immediately halting the current turn and preventing further API expenditure.

### 3. Data Flow
`LLMAdapter` (returns usage) $\rightarrow$ `AgentRunner` (aggregates usage) $\rightarrow$ `FiscalGovernor` (evaluates against budget) $\rightarrow$ `AbortSignal` (triggers containment).

## Implementation Roadmap
1.  **Phase 1 (Telemetry):** Extend `TokenUsage` to include estimated USD cost (requires a provider-specific pricing map).
2.  **Phase 2 (Governance):** Implement the `FiscalGovernor` service.
3.  **Phase 3 (Containment):** Inject the `FiscalGovernor` into the `AgentRunner` lifecycle to enable autonomous circuit breaking.
