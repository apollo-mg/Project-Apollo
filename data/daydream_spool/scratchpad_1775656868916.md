## Proposed Architectural Shift: Structured Injection
Instead of:
```python
if "Brain" in item: status = "OK" if "LLM Brain" in report_text and "OK" in report_text else "FAIL"
```

We should move to a registry-based approach where each diagnostic method registers its own metadata:
1. **Registry Pattern**: Each `check_*` method should be associated with a `Component` object containing its `name`, `roadmap_keywords`, and `status_key`.
2. **Method-Specific Injection**: When updating a component, we update its `Component` definition, not the global `run` loop.
3. **Decoupling**: The `run` method should iterate through the registry, execute the methods, and then compare the results against the roadmap using the metadata provided by the registry, rather than parsing a giant string of text.

## Conclusion
The "destruction" is a logical failure caused by tight coupling between the diagnostic output (strings) and the verification logic (regex/string matching). The fix is to move to a structured, object-oriented registry for diagnostic components.
