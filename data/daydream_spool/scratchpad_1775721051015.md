# Apollo Investigation: Quantization-Sampling Calibration Protocol

## Epiphany Summary
The tension between 14B model scale (Wan2.1) and GGUF quantization (Q4_K_M) requires a calibration protocol mapping precision loss to Flux sampling parameters (`max_shift`, `base_shift`).

## Investigation Goals
1. Locate Wan2.1/GGUF loading logic.
2. Locate Flux sampling node implementations (specifically `max_shift` and `base_shift`).
3. Analyze the relationship between quantization error and sampling noise schedules.
4. Draft a proposal for a calibration protocol.
