    - The "Request cancelled" loop mentioned in the Epiphany is likely the result of the `AbortSignal` being triggered by a higher-level controller (the Pi 5/MoE) when it detects resource pressure or a timeout, which then propagates through the `AgentRunner` and `ToolExecutor`.
- **The "Bridge" Problem:** The "bridge" is the `AgentRunner` and `ToolExecutor` orchestration. The friction occurs because the `AgentRunner` is designed for a "Sovereign Integrity" (sequential, deterministic) loop, but the heavy "Dense" model (the Executor) creates high-entropy, high-resource-demand turns that trigger the `AbortSignal` if the controller (the Pi 5) perceives a delay or a resource spike.

## Architectural Audit
The current decoupling is **insufficient**. The `AbortSignal` is a "hard" kill switch. When the Dense model enters a heavy reasoning phase, the increased latency or RAM usage triggers the controller's timeout/resource-guard, which sends an `abortSignal`. This causes the "Request cancelled" loop because the task is aborted, but the controller might immediately retry or attempt to re-assign, leading to a cycle of cancellations.

## Proposed Architectural Update: "The Decoupling Buffer"
To prevent the "Request cancelled" loops, we need to move from a "Hard Kill" model to a "Pressure-Aware" model.

1.  **Asynchronous State Buffer:** Implement a `TaskStateBuffer` between the Controller and the Executor. Instead of a direct `AbortSignal` kill, the controller should send a `PressureSignal` (e.g., `LOW`, `MEDIUM`, `HIGH`).
2.  **Graceful Degradation:** 
    - `LOW`: Normal operation.
    - `MEDIUM`: The `AgentRunner` should reduce `maxConcurrency` or switch to a more efficient (but less intelligent) model if possible.
    - `HIGH`: The `AgentRunner` should pause non-essential tool execution or signal the LLM to "summarize and conclude" rather than "explore and expand."
3.  **Resource-Aware Scheduling:** The `AgentPool` should monitor System RAM/VRAM and prevent dispatching new tasks if the "Dense" model is currently in a high-entropy phase (detected via token-per-second drops or memory pressure).
