# Architectural Audit: Sovereign Autonomy & Dependency Stress Test
## Status: COMPLETED
## Date: 2025-03-27

### 1. Executive Summary
The audit confirms that while the runtime orchestration (MoE routing, local API calls) is largely decoupled and targets `localhost`, the **provisioning and initialization phase** remains critically dependent on external connectivity (HuggingFace, PyTorch, GitHub). In the event of a geopolitical decoupling (the "March 31st shift"), the system would be unable to scale, recover from disk failure, or provision new experts without an active internet connection.

### 2. Identified Vulnerabilities
*   **Weight Acquisition (Critical):** Scripts in `llama.cpp/ci/run.sh` and `whisper.cpp` rely on `huggingface.co` for model weights and configurations.
*   **Environment Reconstruction (High):** `bootstrap_apollo.sh` and various `legacy_vault` scripts use `pip install` with external indices (`download.pytorch.org`, `wheels.vllm.ai`). An air-gapped environment would fail to rebuild the environment.
*   **Orchestration (Low):** Core Python logic (`shop_bridge.py`, `moe_shootout.py`) correctly uses `127.0.0.1`, demonstrating high local autonomy for existing services.

### 3. Proposed Architectural Pivot: "The Sovereign Reserve"
To achieve total functional autonomy, the architecture must transition from "Download-on-Demand" to "Local-First Provisioning."

#### A. Implementation of a Local Model Registry
*   **Action:** Create a mandatory `/mnt/TG_2TB/Projects/Apollo/models/registry/` directory.
*   **Requirement:** All model weights, `tokenizer.json`, `config.json`, and `special_tokens_map.json` must be stored here.
*   **Code Change:** Update `model_provisioner.sh` to prioritize the local registry. If a model is requested but not in the registry, the system must enter a `WAIT_FOR_MANUAL_SYNC` state rather than attempting a network request.

#### B. Dependency Bundling (Offline-First)
*   **Action:** Transition from `pip install` to a local wheelhouse.
*   **Requirement:** All critical dependencies (PyTorch, Transformers, VLLM) must be downloaded as `.whl` files and stored in a local `vendor/` directory.
*   **Code Change:** Update `bootstrap_apollo.sh` to use `pip install --no-index --find-links=./vendor/ <package>`.

#### C. Telemetry Isolation
*   **Action:** Hard-code the `telemetry_layer.py` to default to a local SQLite sink.
*   **Requirement:** Any external telemetry must be an explicit, opt-in "Bridge" module that can be physically disconnected.

### 4. Conclusion
The MoE swarm is technically optimized for VRAM, but its **operational lifecycle** is currently tethered to the global web. Implementing the "Sovereign Reserve" pattern will transform the architecture from a cloud-dependent tool into a resilient, air-gapped intelligence asset.
