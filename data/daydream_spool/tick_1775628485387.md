# Architectural Proposal: Asymmetry Detection Engine (ADE)

## 1. Executive Summary
Following a subconscious epiphany regarding "Stealth Wins" and "Asymmetry," this proposal outlines the transition of the Sovereign Mind from a passive archive to an active asymmetry-detection engine. The goal is to identify high-value logic and data residing in "orphaned" or "ghost" code segments that are currently disconnected from the primary execution tree.

## 2. Problem Statement: The "Ghost Code" Gap
Current architectural audits (e.g., `sovereign_audit.py`) identify orphaned files but do not evaluate their utility. This creates a "Stealth Win" opportunity: high-relevance logic exists in the filesystem but remains invisible to the active cognitive processes.

## 3. Proposed Solution: The Asymmetry Detection Engine (ADE)

### 3.1 Mathematical Framework
We define the **Asymmetry Score ($\mathcal{A}$)** for any orphaned file $i$ relative to the current system objective $O$ as:

$$\mathcal{A}(i, O) = \frac{\text{Sim}(\text{Embed}(i), \text{Embed}(O)) \cdot \text{Utility}(i)}{\text{Cost}(i)}$$

Where:
- $\text{Sim}(\cdot)$ is the cosine similarity between the semantic embeddings of the file content and the current task.
- $\text{Utility}(i)$ is a heuristic based on the presence of critical patterns (e.g., API calls, complex logic, data structures).
- $\text{Cost}(i)$ is the computational overhead required to integrate or audit the file.

### 3.2 Technical Implementation
- **New Module:** `src/modules/asymmetry_engine.py`
- **Core Workflow:**
    1. **Discovery:** Execute a non-blocking dependency scan to identify orphaned files.
    2. **Semantic Triage:** Use a lightweight LLM (e.g., `llama3.2`) to perform a "quick-look" summary of orphaned files.
    3. **Threshold Trigger:** If $\mathcal{A} > \tau$ (where $\tau$ is the user-defined threshold), the engine generates a `STEALTH_WIN_ALERT` in the `telemetry_layer`.
    4. **Integration:** The alert provides the `orchestrator.py` with a recommendation to ingest the orphaned logic into the active context.

## 4. Impact Analysis
- **Efficiency:** Reduces the search space for new capabilities by proactively surfacing relevant "ghost" code.
- **Resilience:** Increases system intelligence by utilizing latent, unmapped resources.
- **Asymmetry Hunting:** Moves the system from "tracking what is known" to "hunting for what is hidden."

## 5. Implementation Roadmap
1. **Phase 1:** Refactor `sovereign_audit.py` to return structured JSON of orphans.
2. **Phase 2:** Implement `asymmetry_engine.py` with basic semantic similarity.
3. **Phase 3:** Integrate with `telemetry_layer.py` for real-time alerting.
