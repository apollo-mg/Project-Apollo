# Epiphany Investigation: Semantic Stability across Quantization Scales

## Initial Assessment
The epiphany suggests a critical vulnerability: "logic-drift" during the transition between different quantization formats (EXL2 vs GGUF). The core concern is that the 'Teacher' model's intelligence is tied to specific hardware/quantization optimizations rather than semantic stability.

## Hypothesis
The current testing/benchmarking suite likely focuses on throughput (tokens/sec) or perplexity on a single format, but lacks a "Semantic Drift Audit" that compares the output of the same prompt across different quantization scales.

## Investigation Plan
1.  **Audit Benchmarking Logic:** Search for existing benchmarking scripts to see how they evaluate model performance.
2.  **Identify Quantization Logic:** Look for code that handles EXL2 or GGUF loading/inference.
3.  **Search for 'Teacher' or 'Merge' references:** Find the specific implementation of the 'Teacher' model mentioned in the epiphany.
4.  **Propose 'Semantic Stability' Test Suite:** Design a test that compares logit distributions or semantic embeddings of outputs across quantization levels.
