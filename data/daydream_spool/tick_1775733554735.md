# Architectural Audit: Temporal Stutter & Semantic Density

## 1. Epiphany Summary
The system is experiencing a "temporal stutter"—a recursive loop where high-frequency telemetry (timestamps, repetitive status checks) is being ingested as meaningful cognitive memory. This pollutes the LLM's context window with "process noise" rather than "semantic signal."

## 2. Audit Findings
- **Source of Noise:** `telemetry_layer.py` implements an `ImmutableTelemetryLayer` that records every event (e.g., `SYSTEM_CHECK`, `ENTROPY_DETECTED`) with millisecond precision.
- **Evidence:** `telemetry_state_log.jsonl` shows near-identical entries occurring within microseconds of each other, indicating a high-frequency loop.
- **Impact:** The `ingest_logs.py` script reads these logs into chunks and sends them to the LLM. The repetitive telemetry consumes the context window, reducing the capacity for actual technical insights and increasing costs/latency.

## 3. Proposed Architectural Update: Semantic Density Filter

### Objective
Implement a mechanism to distinguish between high-entropy semantic signals and low-entropy process noise.

### Proposed Changes

#### A. Implement `SemanticDensityFilter` in `telemetry_layer.py`
A new class will track the "signature" of recent events (type + description) within a sliding time window. If a signature repeats too frequently, it is flagged as noise.

```python
class SemanticDensityFilter:
    def __init__(self, window_seconds=30, max_repeats=3):
        self.window_seconds = window_seconds
        self.max_repeats = max_repeats
        self.history = [] # List of (timestamp, signature)

    def should_allow(self, event_type, description):
        now = datetime.now(timezone.utc)
        signature = f"{event_type}:{description}"
        
        # Prune old history
        self.history = [h for h in self.history if (now - h[0]).total_seconds() < self.window_seconds]
        
        # Check for repetition
        count = sum(1 for h in self.history if h[1] == signature)
        if count >= self.max_repeats:
            return False
            
        self.history.append((now, signature))
        return True
```

#### B. Integrate Filter into `ImmutableTelemetryLayer`
Modify `record_event` and `record_transition` to consult the filter before calling `_append_to_log`.

```python
# In ImmutableTelemetryLayer.__init__
self.filter = SemanticDensityFilter()

# In record_event
if self.filter.should_allow(event_type, description):
    self._append_to_log(entry)
else:
    # Optionally log a single 'suppressed' entry every N seconds to maintain auditability
    pass
```

#### C. Enhance `ingest_logs.py` (Pre-processing)
Add a regex-based cleaning step in the ingestion pipeline to strip out known high-frequency telemetry patterns (e.g., `SYSTEM_CHECK`) before the text is sent to the LLM. This ensures that even if the log file grows, the "cognitive memory" remains dense.

## 4. Conclusion
By implementing this filter, we decouple the system's operational heartbeat from its cognitive memory, ensuring the Sovereign Engine focuses on architectural evolution rather than its own pulse.
