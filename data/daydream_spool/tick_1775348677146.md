# Architectural Audit: Metabolic Crisis & Swarm Offload Protocol

## Epiphany Summary
The current 'Sovereign Node' architecture suffers from a metabolic crisis: it manages local VRAM through a binary 'all-or-nothing' purge mechanism. When the node hits an Out-of-Memory (OOOM) state, it unloads all models, effectively killing the local 'Digital Brain' context. This creates a fragility that prevents true decentralization.

## Current State Analysis (`vram_management.py`)
- **Mechanism:** `smart_vram_guard` monitors usage against `VRAM_THRESHOLD_MB` (14500MB).
- **Failure Mode:** If the threshold is breached, it calls `unload_comfy_vram`, which triggers a ComfyUI `/free` request to purge all models and wait for a 4GB release.
- **Problem:** This is a "suicide" protocol rather than a "migration" protocol. It destroys the local intelligence to save the hardware.

## Proposed Architectural Shift: 'Swarm Offload' Protocol

Instead of a hard purge, the `smart_vram_guard` must transition from a 'System Administrator' to an 'Autonomic Resource Governor'.

### 1. Implementation of the 'Swarm Offload' Logic
When `used > VRAM_THRESHOLD_MB` and the reserve falls below 0.1GB (100MB), the node should:
1. **Identify Non-Critical Logic:** Categorize running models/agents (e.g., 'Economist', 'Librarian') as 'Migratable'.
2. **Trigger Tailnet Mesh Handshake:** Use the existing network mesh to find a peer node with sufficient VRAM headroom.
3. **State Transfer:** Offload the model weights and the agent's current context/state to the remote node.
4. **Local Cleanup:** Only *after* successful remote handoff does the local node release the VRAM.

def smart_vram_guard(context=None):
    used = get_vram_usage()
    free = VRAM_TOTAL_MB - used
    
    if used > VRAM_THRESHOLD_MB:
        if free < SWARM_RESERVE_THRESHOLD_MB:
            print(f"!!! [METABOLIC CRISIS] VRAM critical ({free:.2f}MB). Initiating Swarm Offload.")
            # Attempt to migrate the 'Economist' or other non-essential logic first
            if trigger_swarm_offload(agent_id="economist_logic"):
                return unload_comfy_vram(unload_models=False) # Partial cleanup
            else:
                return unload_comfy_vram() # Fallback to hard purge
        else:
            print(f"!!! [VRAM ALERT] Usage {used:.2f}MB. Triggering proactive offload.")
            return unload_comfy_vram()
    return True
