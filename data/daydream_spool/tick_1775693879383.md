# Architectural Audit: Liara-Architect Duality & Contextual Drift

## 1. Executive Summary
An investigation into the `MemoryManager` (Liara) and its interaction with the long-term vector store (The Architect) has confirmed a structural paradox. The current compaction mechanism performs highly lossy compression, stripping away the "why" (rationale and state) in favor of "what" (raw facts). This loss of nuance causes "Contextual Drift," where the Architect inherits fragmented truths without the necessary context to maintain long-term structural integrity.

## 2. Root Cause Analysis
**Location:** `/mnt/TG_2TB/Projects/Apollo/modules/memory_core.py`
**Method:** `perform_compaction_flush()`

The current implementation uses a reductive prompt:
`"Summarize the key decisions, architectural facts, and context from our conversation so far. Output only the factual summary."`

**Failure Modes:**
1.  **Information Loss:** The instruction "Output only the factual summary" explicitly forbids the inclusion of the reasoning/intent (the "Contextual Anchors") required by the Architect.
2.  **Metadata Poverty:** The metadata schema for `Document` objects is insufficient, capturing only `source`, `type`, and `timestamp`, failing to record the system state or decision-making context.
3.  **Fidelity Gating:** The system's intelligence is effectively capped by the compression ratio of the `surgeon-heretic:latest` model when forced into a purely factual mode.

## 3. Proposed Architectural Update

### A. Re-engineering the Compaction Prompt
Replace the reductive prompt with a "Contextual Anchor" extraction prompt.

**New Prompt Template:**
```text
Analyze the conversation history and extract a high-fidelity structural summary. 
For every key decision or architectural fact, you MUST provide:
1. [FACT]: The core information or decision.
2. [RATIONALE]: The 'why'—the reasoning, constraints, or intent behind the fact.
3. [STATE]: The surrounding system state, environmental variables, or context at the time.

Format the output as a structured Markdown block to ensure the Architect can parse the nuance.
```

### B. Enhancing Metadata Schema
Update the `Document` metadata in `perform_compaction_flush` to include a `context_hash` or `state_snapshot` to allow the Architect to reconstruct the environment.

```python
# Proposed Metadata Update
doc = Document(
    page_content=structured_summary,

    }
)
```
