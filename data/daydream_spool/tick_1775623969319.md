# Architectural Audit: Sensory Integrity Implementation

## 1. Problem Statement
The current vision pipeline (`desktop_eyes.py` -> `buddy_agent.py` -> `ApolloAgentSession`) lacks a validation layer. It assumes that a successful subprocess call to `spectacle` or `ImageGrab` results in a valid, timely, and accurate representation of reality. This creates a vulnerability where the agent may reason based on stale, corrupted, or "tool-induced" artifacts (e.g., a black screen, a frozen frame, or a failed capture that leaves a zero-byte file).

## 2. Audit Findings
- **`desktop_eyes.py`**: Performs raw capture via `subprocess.run(["spectacle", ...])`. It returns the path immediately after the call without verifying the file's content or freshness.
- **`buddy_agent.py`**: Extracts `image_path` from user input and passes it directly to the session.
- **`modules/agent_session.py`**: Passes the `image_path` to `llm_interface.stream_llm`. There is no check to ensure the image is actually "live".
- **`buddy_guardian.py`**: Currently only performs *static* integrity checks (file hashes of the codebase). It does not monitor *dynamic* sensory integrity.

## 3. Proposed Architectural Update: "Sensory Integrity Layer"

### A. New Module: `modules/sensory_integrity.py`
Implement a dedicated validator to be used by both the capture tool and the agent session.

```python
import os
import time
from PIL import Image

class SensoryIntegrityError(Exception):
    """Raised when visual input fails validation."""
    pass

def validate_sensory_input(image_path: str, max_age_seconds: float = 5.0):
    """
    Performs a multi-stage validation of the visual input.
    1. Existence: Does the file exist?
    2. Freshness: Is the file modification time within the allowed window?
    3. Readability: Can PIL actually open and decode the image?
    4. Content: Is the image size suspiciously small (potential black/empty frame)?
    """
    if not os.path.exists(image_path):
        raise SensoryIntegrityError(f"Image file missing: {image_path}")

    # 1. Freshness Check
    mtime = os.path.getmtime(image_path)
    age = time.time() - mtime
    if age > max_age_seconds:
        raise SensoryIntegrityError(f"Stale sensory input: Image is {age:.2f}s old.")

    # 2. Readability & Content Check
    try:
        with Image.open(image_path) as img:
            img.verify() # Verify file integrity
            # Re-open to check dimensions/content
            with Image.open(image_path) as img_check:
                if img_check.size[0] < 10 or img_check.size[1] < 10:
                    raise SensoryIntegrityError("Invalid image dimensions (too small).")
                if img_check.size[0] * img_check.size[1] < 1000: # Very small pixel count
                    raise SensoryIntegrityError("Suspiciously low pixel count (potential empty frame).")
    except Exception as e:
        raise SensoryIntegrityError(f"Visual corruption detected: {e}")

    return True
```

## 4. Impact Assessment
- **Reliability**: High. Prevents the agent from hallucinating based on stale or broken visual data.
- **Latency**: Minimal. `PIL.verify()` and `os.path.getmtime()` are extremely fast.
- **Complexity**: Low. Adds one module and two small integration points.
