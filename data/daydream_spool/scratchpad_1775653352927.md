## Findings: AgentRunner Analysis
- `AgentRunner.stream` (lines 207-456) implements the core agentic loop.
- It uses a `while (true)` loop (line 245) that continues until `maxTurns` is reached or no more tool calls are requested.
- It enforces "Sovereign Integrity" by only processing the *first* tool call in a turn (lines 358-364), even if the LLM requests multiple. This is a deliberate architectural choice to force a deterministic Observe -> Act -> Observe loop.
- Timing is captured for each tool call (lines 370, 385), but it is only stored in the `record` (line 389) and returned in the `RunResult`.
- There is no mechanism to detect "stuttering" (high-frequency, low-progress loops) where the agent might be executing many small, repetitive, or circular tool calls that don't advance the macro-level goal.

## Identified Vulnerability
The "stuttering" mentioned in the epiphany is highly likely to manifest as a sequence of turns where:
1. The agent calls a tool.
2. The tool returns a result.
3. The agent calls the *same* tool or a very similar tool with slightly different parameters.
4. This repeats until `maxTurns` is hit.

Current monitoring only tracks `turns` and `tokenUsage`. It does not track the *semantic distance* or *temporal entropy* between turns.

## Proposed Solution: Temporal Entropy Monitor
I propose adding a `TemporalEntropyMonitor` that:
1. **Tracks Turn Signatures:** Generates a lightweight hash or signature of each turn (e.g., `tool_name + input_hash`).
2. **Detects Repetition:** Monitors the frequency of identical or near-identical signatures within a single `run`.
3. **Calculates Entropy:** If the "entropy" (diversity of actions) drops below a threshold while the turn count is high, it flags a "stuttering" state.
4. **Integration:** This monitor should be integrated into `AgentRunner` and can be used to trigger an early exit or a "macro-level correction" prompt.

## Implementation Plan
1. **Define `TemporalEntropyMonitor` class:**
   - `recordTurn(toolName: string, input: any)`

3. **Update `RunResult`:**
