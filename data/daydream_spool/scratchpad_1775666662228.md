# Apollo Investigation Log: RDNA 4 DMA Protocol Incompatibility

## Initial Hypothesis
The 'Illegal Memory Access' error is not a data corruption issue but a protocol mismatch during DMA transfers between Host and RDNA 4. The `comfy.model_management.cast_to` function is likely triggering invalid strided memory access patterns that the RDNA 4 DMA engine cannot handle, leading to catastrophic failure during tensor transfers (VAE/ControlNet).

## Investigation Plan
1.  **Locate `comfy.model_management.cast_to`**: Find the exact implementation of the casting logic.
2.  **Trace Dependencies**: Map all calls to `cast_to` within the codebase to identify high-risk areas (VAE, ControlNet, Model Loading).
3.  **Analyze Casting Logic**: Determine if the logic uses non-contiguous memory views or specific strides that might conflict with RDNA 4 DMA requirements.
4.  **Draft Proposal**: Propose a 'Super Safe Transfer' pattern to replace or wrap the existing casting logic for RDNA 4 hardware.
