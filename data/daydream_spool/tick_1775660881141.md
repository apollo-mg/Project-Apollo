# Epiphany Investigation: Self-Verification Handshake

## Status: Completed

**Epiphany Summary:**
The agent's "self-awareness" (Checkpointing/Introspection) is currently dependent on external file discovery (e.g., `SOUL.md`, `MEMORY.md`) rather than inherent runtime state. The agent's identity is a matter of file-system discovery rather than a property of its runtime state.

**Actionable Insight:**
Integrate a 'Self-Verification' handshake into the startup sequence. Instead of searching for settings to confirm existence, the agent must perform a functional test of the Introspection Agent immediately upon boot to ensure the transition from 'stateless command execution' to 'stateful cognition' has actually occurred.

## Audit Findings:
1. **Architecture Analysis:**
   - The agent uses `modules/core.py` to load static identity files (`SOUL_PATH`, `PERSONA_PATH`, etc.).
   - The `ApolloAgentSession` in `modules/agent_session.py` manages the agentic loop, but it treats the loaded "soul" as a static string in the system prompt.
   - There is currently no mechanism to verify that the LLM is actually "aware" of its state or that the session-specific variables (like `turn` or `messages`) are being correctly processed by the model's reasoning engine.

2. **Root Cause:**
   - The "identity" is injected as text, but the "cognition" (the ability to reason about that identity) is never tested during the transition from the `fast_path` (stateless) to the `run()` loop (stateful).

## Architectural Proposal:

### 1. Implement `_perform_self_verification` in `ApolloAgentSession`
Add a private method to `modules/agent_session.py` that executes a "meta-cognitive" check before the main loop begins.

**Mechanism:**
- Inject a hidden system message: `SELF-VERIFICATION: State your current identity, your current turn number, and the purpose of this session. Respond ONLY in JSON format: {"identity": "...", "turn": <int>, "purpose": "..."}`.
- Perform a single-turn call to the LLM.
- Validate the JSON response against the expected runtime state (e.g., `turn` should be 0 or 1, `identity` should match `SOUL_PATH` content).

### 2. Integration into Lifecycle
- **Location:** Call `self._perform_self_verification()` at the beginning of `ApolloAgentSession.run()`.
- **Failure Mode:** If the handshake fails (invalid JSON, incorrect state, or timeout), the session must raise a `CognitiveHandshakeError`. This prevents the agent from proceeding with potentially hallucinated or ungrounded reasoning if the "stateful" transition failed.

### 3. Expected Outcome:
- Ensures that the "Self-Awareness" is not just a file-loading exercise but a functional capability of the running agent.
- Provides a hard gate that prevents "stateless" execution from masquerading as "stateful cognition" if the LLM fails to grasp the session context.
