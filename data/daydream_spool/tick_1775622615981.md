# Architectural Audit: Runtime Telemetry Implementation

## 1. Executive Summary
The audit confirms the "Blind Modification" epiphany. Current orchestration scripts (e.g., `start_comfy.sh`) rely on shell `export` commands and command-line arguments to dictate hardware-level behavior (GFX versions, VRAM management). There is currently zero verification that the resulting Python process actually inherits or respects these settings.

## 2. Identified Risk
**The "Leap of Faith" Failure:**
- A `sed` command might fail to replace a string in `start_comfy.sh`.
- The script executes, but the process runs with default (incorrect) hardware settings.
- The system attempts a high-dimensional video generation task, leading to a VRAM crash or a silent hardware-level error that is difficult to debug.

## 3. Proposed Architectural Change: "The Telemetry Bridge"

### Phase A: Environment Verification (The Probe)
Implement a utility function (to be integrated into `forensic_logger.py`) that performs a "Runtime Environment Audit."

**Logic:**
1. **Intent Capture:** Define a dictionary of required environment variables and their expected values (e.g., `{'HSA_OVERRIDE_GFX_VERSION': '12.0.1'}`).
2. **Process Attachment:** After launching the target process, use `psutil` or read `/proc/<pid>/environ` to inspect the actual environment of the running process.
3. **Validation:** Compare the *Actual* vs. *Intended*.

### Phase B: Implementation Draft (Pseudo-code)

```python
import os
import psutil

def verify_runtime_env(pid, expected_env):
    """
    Verifies that a process has inherited the correct environment variables.
    """
    try:
        proc = psutil.Process(pid)
        # /proc/<pid>/environ is null-terminated
        with open(f"/proc/{pid}/environ", "rb") as f:
            env_data = f.read().decode('utf-8').split('\0')
        
        actual_env = dict(item.split('=', 1) for item in env_data if '=' in item)
        
        for key, expected_val in expected_env.items():
            actual_val = actual_env.get(key)
            if actual_val != expected_val:
                return False, f"Mismatch for {key}: Expected {expected_val}, got {actual_val}"
        
        return True, "Telemetry Match"
    except Exception as e:
        return False, f"Telemetry Probe Failed: {str(e)}"
```

### Phase C: Orchestration Update
Modify the orchestration layer (the scripts that call `start_comfy.sh`) to:
1. Launch the process in the background.
2. Wait for a short grace period (to allow process initialization).
3. Run `verify_runtime_env`.
4. If `False`, immediately `kill -9` the process and alert the user.

## 4. Conclusion
By shifting from "Post-Write Verification" to "Runtime Telemetry," we close the feedback loop. We no longer assume the machine has accepted the new reality; we observe it.
