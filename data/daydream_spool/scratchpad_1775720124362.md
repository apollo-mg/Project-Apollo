## Epiphany Summary
The agent may be defaulting to raw shell commands (SSH + grep/tail) because specialized tools are missing on remote nodes, violating the "Critical Instructions" to use tool-driven architecture.

## Investigation Plan
1. Search for remote IP addresses (e.g., 10.0.0.5) in the codebase.
2. Search for SSH command patterns in the codebase.
3. Identify the definition of "custom tools".
4. Check for deployment scripts or configurations for remote nodes.

- `log_epiphany.md` indicates that `10.0.0.5` is a host that has experienced service outages (Apollo Bridge and Whisper services).
