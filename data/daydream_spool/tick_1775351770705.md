## 2. Current State Audit (`librarian_ingeest.py`)
The current implementation of `librarian_ingeest.py` performs basic deduplication using file hashes and URL IDs:
- **PDFs:** Uses `compute_sha256(file_path)` and checks `vector_store.get(where={"file_hash": file_hash})`.
- **URLs:** Uses `hashlib.sha256(url.encode())` and checks `vector_store.get(where={"url_id": url_id})`.

**Critical Vulnerabilities Identified:**
1. **Semantic Overlap:** The current check is purely identity-based (exact hash match). It does not detect if two different files contain the same semantic content (e.g., a PDF version and a web-scraped version of the same whitepaper).
2. **Lack of a 'Knowledge Manifest':** There is no centralized registry (Manifest) to track the "state of truth" for ingested entities. The system relies on the VDB's internal metadata, which is prone to fragmentation if the VDB itself becomes inconsistent.
3. **No Contextual Defragmentation:** There is no mechanism to "clean" or "merge" existing knowledge before adding new knowledge, leading to a "bloated" semantic space.

## 3. Proposed Architectural Update: The 'Context Defragmentation' Protocol

I propose the implementation of a **Semantic Deduplication Layer** to be integrated into the Librarian workflow.

### Phase A: The Knowledge Manifest (`knowledge_manifest.json`)
Instead of relying solely on VDB metadata, we must maintain a lightweight, high-integrity JSON manifest in `/mnt/TG_2TB/Projects/Apollo/vault/knowledge_manifest.json`.
- **Fields:** `entity_id`, `content_hash`, `semantic_fingerprint` (centroid of embeddings), `source_type`, `last_updated`.

### Phase B: Semantic Fingerprinting
Before full ingestion, the Librarian must:
1. **Extract Content:** Perform a lightweight extraction.
2. **Generate Fingerprint:** Compute a low-dimensional embedding (the "fingerprint") of the content.
3. **Cross-Reference:** Query the VDB for existing embeddings within a specific distance threshold ($\epsilon$) of the new fingerprint.
4. **Decision Logic:**
   - If $\text{dist}(\text{new}, \text{existing}) < \epsilon$: **Reject/Merge** (Semantic Duplicate).
   - If $\text{dist}(\text{new}, \text{existing}) \ge \epsilon$: **Ingest** (New Knowledge).
