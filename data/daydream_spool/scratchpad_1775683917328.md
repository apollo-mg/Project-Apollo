# Epiphany Investigation: Temporal Footprint Categorization
## Timestamp: 2025-05-22 (Simulated)
## Status: Initializing Audit

### Hypothesis
The current architecture likely treats all model execution nodes with a uniform resource management strategy. The "Epiphany" suggests that this leads to inefficiency. 

**Goal:** Identify where models are instantiated and managed in the codebase to see if there is a distinction between 'Transient/Heavy' (e.g., T5, large encoders) and 'Persistent/Generative' (e.g., LLMs, continuous agents).

### Audit Plan
1.  **Scan for Model Loading/Instantiation:** Search for keywords like `load_model`, `from_pretrained`, `AutoModel`, `pipeline`, `device`, `offload`.
2.  **Identify Workflow Nodes:** Look for classes or functions that define "nodes" or "steps" in the execution pipeline.
3.  **Analyze Resource Management:** Check how memory/VRAM is managed during these steps. Is there a global manager or is it per-node?
4.  **Categorization Check:** Determine if there is any existing metadata or logic that distinguishes between model types.
