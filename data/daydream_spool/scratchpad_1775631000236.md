## Timestamp: 2026-02-27

The Epiphany suggests a shift from "biological survival" (timeouts/error handling) to "agency" (Action Tags). 
The goal is to map semantic strings to OS/hardware functions.

### Analysis of `apollo_foreman.ts`
- The Foreman is the "execution arm" that reads "Tick Proposals" and converts them into a "Master Action Plan".
- It uses a `ToolRegistry` and `ToolExecutor` to perform actions.
- The current toolset is limited to: `bash`, `file_read`, `file_write`, `file_edit`, `grep`.
- **The Gap:** There is no semantic layer between the "Master Action Plan" (textual instructions) and the "Tools" (low-level execution). The Foreman has to manually translate "Implement X" into a series of `file_edit` or `bash` calls.
- **The Opportunity:** "Action Tags" would allow the Foreman (or the Daydreamer) to emit a single semantic tag (e.g., `<tag:RESTART_SERVICE_APOLLO>`) which the `ToolExecutor` would then map to a specific, safe, and optimized sequence of OS commands. This decouples the *intent* from the *implementation*.

### Proposed Architecture for Action Tags
1. **Schema Definition:** A JSON-based schema defining `ActionTags`.
   - `tag_name`: The semantic identifier (e.g., `SYS_REBOOT`, `SERVICE_RESTART`, `MEMORY_FLUSH`).
   - `parameters`: Expected arguments (e.g., `service_name`).
   - `handler`: The internal function/command to execute.
2. **Action Interpreter:** A new component in the `ToolExecutor` or a standalone `ActionInterpreter` that:
   - Scans LLM output for `<tag:NAME(args)>` patterns.
   - Validates the tag against the schema.
   - Dispatches the mapped OS/Hardware command.
3. **Integration:**
   - Update `ToolRegistry` to include the `ActionTagInterpreter`.
   - Update `AgentRunner` system prompts to encourage the use of semantic tags for high-level system operations.

### Audit Conclusion
The system is currently in the "biological survival" phase (using tools to fix things). The "Action Tag" implementation is the missing "nervous system" that allows for high-level agency without the overhead of manual tool orchestration for every single system-level task.
