## Architectural Proposal

### Solution A: Systemd Service (Recommended)

**File:** `/etc/systemd/system/llama-server.service`

```ini
[Unit]
Description=LLaMA Server for Eternal Memory Persistence
After=network-online.target
Requires=network-online.target

[Service]
Type=simple
User=ubuntu
Group=ubuntu
WorkingDirectory=/home/ubuntu

# Primary llama-server process
ExecStart=/bin/bash -c "llama-server --port 11436 --host 0.0.0.0 --model /mnt/TG_2TB/Projects/Apollo/models/Qwen3.5-27B-Claude-4.6-OS-Auto-Variable-Heretic-Uncensored-Thinking.i1-IQ3_M.gguf --n-gpu-layers 99 --n-predict 1024 --mlock"

# Ensure it restarts on failure
Restart=always
RestartSec=10

# Prevent restart loop on boot
TimeoutStopSec=10

[Install]
WantedBy=multi-user.target
```

**Activation:**
```bash
sudo systemctl enable llama-server
sudo systemctl start llama-server
```
