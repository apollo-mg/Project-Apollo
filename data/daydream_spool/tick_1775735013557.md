# Architectural Audit & Proposal: Dependency Decay and Initialization Stabilization

## 1. Executive Summary
The system is experiencing "dependency-driven architecture collapse" due to the use of deprecated `pkg_resources` within the underlying environment and a lack of formalized configuration for orchestration layers (`accelerate`). This leads to redundant initialization cycles and potential instability in audio synthesis (Vocos).

## 2. Findings
- **Dependency Obsolescence**: While the core Apollo codebase does not explicitly call `pkg_resources`, the environment (as evidenced by `ai_move.log`) is saturated with it. This triggers deprecation warnings that interrupt the clean execution of the model's "voice" (Vocos).
- **Initialization Loops**: The system appears to be re-verifying or re-downloading components during every startup, likely due to the absence of a static `accelerate` configuration and the presence of legacy paths in the search/scan vectors.
- **Architectural Drift**: The "recursive loop of initialization" suggests that the system is attempting to rebuild its foundation every time it wakes, rather than operating from a stable, pre-configured state.

## 3. Proposed Code & Configuration Changes

### A. Formalize `accelerate` Configuration
**Action**: Create a static `accelerate_config.yaml` to prevent the system from re-detecting hardware/environment on every run.

```yaml

num_processes: 1
rdzv_backend: static
same_device: null
tpu_devices: null

```

### B. Migrate to `importlib.metadata`
**Action**: For any future internal modules requiring version/metadata checks, strictly prohibit `pkg_resources`.

**Example Migration**:
*Old (Deprecated):*
```python
import pkg_resources
version = pkg_resources.get_distribution("vocos").version
```

*New (Standard):*
```python
from importlib.metadata import version
current_version = version("vocos")
```

### C. Vocos Initialization Singleton
**Action**: Ensure Vocos is loaded as a managed resource to prevent redundant model downloads/initializations.

```python
# Proposed implementation in audio_engine.py
class VocosManager:
    _instance = None
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super(VocosManager, cls).__new__(cls)
            # Load model once
            cls._instance.model = load_vocos_model() 
        return cls._instance
```
