# Apollo Investigation: TG_2T to TG_2TB Migration Audit

## Objective
Audit the codebase to ensure that file pathing logic and glob patterns for JSON transcript loading are dynamically updated to reflect the new `/mnt/TG_2TB/` mount point, preventing a continuity break.

## Hypotheses
1.  **Hardcoded Paths:** The path `/mnt/TG_2T/` is hardcoded in a configuration file or a core logic module.
2.  **Static Glob Patterns:** The pattern used to find JSON files is tied to a specific directory structure that has changed.
3.  **Environment Variable Neglect:** The system relies on environment variables that haven't been updated or are being ignored in favor of hardcoded strings.
