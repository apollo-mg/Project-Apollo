# Architectural Proposal: Salience-Based Context Expansion Protocol

## 1. Problem Statement
The system currently exhibits "cognitive looping" where high-weight/salient information (e.g., specific architectural concepts like AWQ) is repeatedly reinforced in the immediate context (Tier 1) without expanding the surrounding semantic context. This leads to a narrow, repetitive context window that fails to integrate the salient information into the broader architectural understanding.

## 2. Proposed Solution: Salience-Based Expansion Protocol
Instead of treating salient information as a static weight to be repeated, we will use its presence as a trigger to aggressively expand the context window with semantically related, lower-weight information.

### 2.1 Core Mechanism
When a `MemoryEntry` with a high `salience_score` is accessed or updated in the `Tier1WorkingBuffer`:
1. **Trigger:** The `TieredMemorySystem` detects the high salience.
2. **Expansion:** The system performs a `semantic_search` in `Tier2` and `Tier3` using the vector of the salient entry.
3. **Activation:** The top-$K$ related entries are "activated" and promoted to `Tier1`, effectively scaling the activation of the surrounding architectural concepts.

## 3. Required Code Changes

### 3.1 `src/modules/memory_system.py`

#### A. Update `MemoryEntry`
Add a `salience_score` field to allow explicit weighting of entries.
```python
@dataclass
class MemoryEntry:
    id: str
    content: str
    timestamp: float
    tier: int
    salience_score: float = 0.0  # NEW: Explicit salience for expansion triggers
    metadata: Dict[str, Any] = field(default_factory=dict)
    vector: Optional[List[float]] = None
```

#### B. Update `TieredMemorySystem`
Implement the expansion logic within the access/put flow.
```python
class TieredMemorySystem:
    # ... existing init ...
    
    def _trigger_expansion(self, salient_entry: MemoryEntry):
        """Aggressively scales activation of related concepts."""
        if salient_entry.salience_score < SALIENCE_THRESHOLD:
            return

        # 1. Search Tier 2 for semantic neighbors
        related_tier2 = self.tier2.semantic_search(salient_entry.vector, top_k=5)
        for entry in related_tier2:
            # Promote to Tier 1 to expand context
            self.tier1.put(entry.id, entry, metadata={"expanded_via": salient_entry.id})

        # 2. Search Tier 3 for deeper architectural context
        if salient_entry.vector is not None:
            related_tier3 = self.tier3.semantic_search(salient_entry.content, top_k=3)
            for entry in related_tier3:
                self.tier1.put(entry.id, entry, metadata={"expanded_via": salient_entry.id})

    def put(self, entry: MemoryEntry) -> str:
        # ... existing put logic ...
        # After putting in Tier 1/2:
        self._trigger_expansion(entry)
        return entry.id
```

## 4. Impact Assessment
- **Complexity:** Low-Medium. Requires careful tuning of `SALIENCE_THRESHOLD` and `top_k` to prevent context flooding.
- **Performance:** Moderate impact on `put` operations due to additional semantic searches.
- **Architectural Integrity:** High. Directly addresses the "cognitive loop" identified by the subconscious daemon.
