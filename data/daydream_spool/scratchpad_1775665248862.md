# Epiphany Investigation: Capability Handshake for Workstation Delegation
## Timestamp: 2025-05-22 (Simulated)
## Status: Investigating

### Hypothesis
The current `delegate_to_workstation` mechanism assumes a static intelligence level. If the local LLM (Ollama/vLLM/etc.) on port 11435 changes models based on VRAM availability, the agent might send a high-reasoning task to a low-parameter model, leading to failure or hallucination.

### Investigation Plan
1. Locate the `delegate_to_workstation` tool definition.
2. Identify the current implementation of the workstation communication.
3. Determine how to query the model identity from the endpoint (likely `/api/tags` or `/api/show` if it's Ollama).
4. Propose a schema update to include a capability check.

### Findings
- **Current Implementation:** `delegate_to_workstation.py` uses a hardcoded `OLLAMA_MODEL = "deepseek-r1:14b"`.
- **The Fallacy:** It assumes the model at `10.0.0.5:11434` is always `deepseek-r1:14b`. If the workstation's VRAM state changes and it loads a smaller model (e.g., `llama3:8b`), the `delegate_task` function will still send requests expecting `deepseek-r1:14b` behavior, or worse, it will just use whatever is currently loaded without verifying if it's capable of the task.
- **The Gap:** There is no check to see what model is *actually* running.

### Proposed Architectural Update
1. **Capability Handshake:**
   - Before `delegate_task` executes, it should call `GET http://10.0.0.5:11434/api/tags` (Ollama's endpoint to list models) or `GET http://10.0.0.5:11434/api/show` (to check specific model details).
   - Alternatively, query the active model via `GET http://10.0.0.5:11434/api/ps` (if available) or by checking the response of a lightweight probe.
2. **Complexity Mapping:**
   - Define a mapping of `model_name -> capability_score`.
   - If `task_complexity > current_model_capability`, return an error: `"Error: Current workstation model [model_name] is insufficient for this cognitive load. Please upgrade VRAM/Model."`
3. **Code Changes:**
   - Update `delegate_to_workstation.py` to include a `get_active_model()` function.
   - Implement a `check_capability(model_name, instruction_complexity)` logic.
