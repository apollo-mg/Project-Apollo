### Conclusion/Proposal
The "K-type transformation" is a conceptual requirement for all data-transforming primitives. To implement this, we should:
1. Define a standard `KTransform` interface or pattern.
2. Update the `ToolExecutor` or the `ToolDefinition` to enforce that `execute` receives a deep-cloned version of the input if the schema contains transformations.
3. Alternatively, mandate that all `execute` implementations for tools with `z.effects()` must perform an internal deep clone before applying any logic.
