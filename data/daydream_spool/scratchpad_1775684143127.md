# Apollo Investigation: Epiphany Audit
## Timestamp: 2025-05-22 (Simulated)
## Epiphany: The 'Hybrid' Handoff Architecture

### Initial Hypothesis
The current architecture likely suffers from "monolithic node" syndrome, where components attempt to hold onto state or model weights longer than necessary. The Epiphany suggests that we should optimize for the *handoff* between heavy encoders (like T5) and generation models (video/image) to maximize VRAM availability.

### Investigation Plan
1.  **Identify Encoder/Generator Interface:** Search for T5 usage and video generation logic.
2.  **Audit VRAM Management:** Look for `vram_management.py` and how it's used in the pipeline.
3.  **Search for 'Universal Node' patterns:** Check `src` and `modules` for rigid class structures that might be preventing efficient offloading.
4.  **Analyze Handoff Mechanisms:** Look for how data (embeddings/latents) is passed between stages.
