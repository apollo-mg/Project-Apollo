# Investigation Start: Epiphany regarding Hardware-Specific vs. Agnostic Architecture
## Hypothesis
The current codebase may contain hardcoded dependencies on CUDA-specific kernels (SageAttention) that impede ROCm/GGUF compatibility. The goal is to audit the dependency tree and kernel implementations to see if a pivot to GGUF-centricity is feasible without losing critical performance.

## Plan
1. Audit dependency files (pyproject.toml, requirements.txt, etc.) for SageAttention/CUDA-specific constraints.
2. Search for SageAttention usage in the codebase.
3. Evaluate the impact of removing/de-prioritizing specialized kernels.
