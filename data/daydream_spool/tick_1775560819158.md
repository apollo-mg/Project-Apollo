# Architectural Audit: ComfyUI Path Fragmentation & Dependency Fragility

## 1. Epiphany Validation
The subconscious epiphany is **VALID**. 

Current filesystem patterns (as observed in `legacy_vault/tmp/ai_move.log` and various shell scripts) indicate that ComfyUI-related assets and model paths are being mapped using highly specific, absolute paths (e.g., `/media/mark/TG 2TB/AI/stable-diffusion/...`). 

This "granular fragmentation" creates several critical risks:
- **Mount Point Fragility:** The system relies on the specific mount point `/media/mark/TG 2TB/`. If the drive is mounted elsewhere (e.g., `/mnt/TG_2TB/`), all hardcoded paths in configuration files, scripts, and environment variables will break.
- **Linear Complexity Growth:** Every new model type or subdirectory requires a manual update to the path mapping, increasing the probability of configuration drift.
- **Environment Inconsistency:** The presence of both `/media/mark/TG 2TB/` and `/mnt/TG_2TB/` in logs suggests that the system is already suffering from path ambiguity.

## 2. Audit Findings
- **Path Inconsistency:** Logs show a mix of `/media/mark/TG 2TB/` and `/mnt/TG_2TB/`. This confirms that the system is sensitive to how the external volume is mounted.
- **Manual Overhead:** The `ai_move.log` shows explicit, line-by-line copying of deep directory structures, which is a symptom of the "list of dependencies" problem described in the epiphany.
- **Lack of Abstraction:** There is no evidence of a unified `BASE_MODEL_DIR` variable being used to resolve these paths dynamically.

## 3. Proposed Architectural Transition

### Phase A: Symlink Consolidation (Immediate)
Instead of mapping individual subdirectories, create a unified symlink structure within the ComfyUI base directory.
- **Action:** Create a `models_external` symlink within the ComfyUI root that points to the root of the external model repository.
- **Benefit:** ComfyUI will see a standard local directory, while the actual data resides on the `TG_2TB` drive.

### Phase B: Variable-Based Configuration (Mid-term)
Transition all shell scripts (`start_architect.sh`, `start_coordinator_experimental.sh`) and Python configuration loaders to use a single environment variable for the external volume.
- **Proposed Change:**
  ```bash
  # Instead of:
  # MODEL="/mnt/TG_2TB/AI/Models/Qwen 3.5/..."
  
  # Use:
  export AI_ASSET_ROOT="/mnt/TG_2TB/AI"
  MODEL="$AI_ASSET_ROOT/Models/Qwen 3.5/..."
  ```

### Phase C: Path Normalization Utility
Implement a small utility within the `Apollo` core to resolve paths. This utility should detect the mount point of the `TG_2TB` drive and automatically adjust the `AI_ASSET_ROOT` at runtime, preventing failures due to mount-point shifts.

## 4. Conclusion
The transition from **explicit per-directory mapping** to **symbolic link abstraction** and **base-path variable usage** is required to stabilize the ComfyUI environment and reduce the operational overhead of managing the model library.
