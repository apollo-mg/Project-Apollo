# Epiphany Investigation: Source of Truth Protocol
## Status: Investigating
## Objective: Audit the codebase to identify the "silent drift" between the desktop (mind) and the Pi (body) and propose a handshake mechanism.

### Initial Observations
- The epiphany suggests a synchronization issue between the control script (desktop) and the execution environment (Pi).
- Current architecture seems to rely on manual or implicit synchronization.
- Key files identified in root: `apollo.py`, `apollo_heartbeat.py`, `apollo_bridge.log`.

### Hypothesis
The system lacks a formal verification step during the initialization phase where the Pi validates its local script version against the intended version defined by the architect.
