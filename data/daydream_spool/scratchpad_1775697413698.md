
# Epiphany Investigation: Memory Wall vs. Compute Potential
## Timestamp: 2024-05-22 (Simulated)
## Status: Initializing Audit

### 1. Hypothesis
The current architecture suffers from a mismatch between RDNA 4 compute capabilities and the 16GB VRAM ceiling. Current optimizations focus on throughput (speed) rather than density (efficiency).

### 2. Audit Objectives
- Identify current quantization/precision implementations.
- Locate DMA transfer logic or memory management routines.
- Check for "software-level gymnastics" (fragmentation management, GGUF loaders, etc.) that might be adding overhead.
- Assess if current compute kernels are being starved by memory latency/bandwidth.

### 3. Initial Scan
- Search for quantization logic (FP8, Q4, GGUF).
- Search for memory allocation/DMA management.
