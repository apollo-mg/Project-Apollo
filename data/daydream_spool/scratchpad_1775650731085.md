# Investigation: ROCm 'TheRock' Modularization & RX 9070 XT Support

## Hypothesis
The transition to 'TheRock' modular ROCm is a structural alignment with CachyOS's modularity. The primary challenge is integrating this into the `pacman` ecosystem to support new hardware targets like `gfx1201/1200` (RX 9070 XT) without manual dependency management.

## Initial Audit Steps
1. Search for 'TheRock' or 'ROCm' related configurations in the codebase.
2. Check for existing `gfx1201` or `gfx1200` target definitions.
3. Investigate the current ROCm packaging/build logic to identify potential bottlenecks in the `pacman` integration.
## Findings
- `gfx1201` and `gfx1200` targets are not currently present in the codebase, confirming that the hardware support for RX 9070 XT (RDNA 4) is not yet integrated.
- `synthesizer_batch.log` indicates that ROCm/HIP/RDNA 4 instability is already being noted as a cause for "silent data corruption" and "RMS Norm" errors. This suggests that while the hardware might be present in some testing environments, the software stack is not yet stable or properly integrated.
- The current codebase has placeholders for ROCm VRAM querying (`scheduler.ts`), but no actual implementation for the modular 'TheRock' system.

## Conclusion
The Epiphany is valid. The lack of `gfx120x` targets and the reported instability in logs suggest that we are currently in a "pre-integration" state where we are seeing the symptoms of hardware/driver mismatch. The transition to 'TheRock' modularity is required to move away from the monolithic ROCm approach which is currently failing to provide stable RDNA 4 support.

## Proposed Action Plan
1. **Monitor CachyOS Repositories:** Track the release of modular ROCm packages.
2. **Architectural Update:** Once 'TheRock' packages are available, implement a native integration layer in the orchestrator to handle `gfx120x` targets via the system's package manager rather than manual environment overrides.
3. **Dependency Mapping:** Map the new modular ROCm dependencies to ensure the `pacman` ecosystem can resolve them without conflicts.
