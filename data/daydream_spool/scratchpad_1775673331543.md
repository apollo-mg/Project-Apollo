# Apollo Investigation: Singleton Model Registry Epiphany

## Objective
Investigate the "crisis of identity" in the loader mechanism. Determine if redundant model allocations are occurring due to lack of a global singleton registry.

## Hypothesis
The current `Loader` implementation likely instantiates new objects for every request, even if the underlying file/resource is identical, leading to memory fragmentation and redundant RDNA 4 allocations.
