# Architectural Proposal: Mobile Node Standardization Protocol

## 1. Executive Summary
The investigation confirms that the transition between mobile (Termux) and desktop (Ubuntu) environments via Tailscale is currently an uncodified, manual process. To satisfy the "fluidity" requirement of the lab's architecture, this transition must be standardized into a repeatable, automated "Mobile Node" configuration.

## 2. Problem Statement
The current lack of a standardized provisioning script for mobile nodes introduces:
- **Operational Friction:** Manual verification of SSH, Mosh, and Tailscale status.
- **Architectural Fragility:** The "bridge" between mobile and desktop is a dependency that is not explicitly managed or monitored.
- **Inconsistency:** Risk of divergent configurations between mobile and desktop nodes.

## 3. Proposed Solution: `mobile-node-provision.sh`
A new configuration script should be introduced to the `scripts/` or `provisioning/` directory. This script will automate the following:

### A. Connectivity Verification
- **Tailscale Status:** Check if `tailscale status` returns an active connection to the mesh network.
- **SSH Daemon:** Verify `sshd` is running and listening on the expected port.
- **Mosh Readiness:** Ensure `mosh-server` is available and accessible.

### B. Environment Standardization
- **Dependency Check:** Verify presence of essential tools (`git`, `curl`, `tailscale`, `mosh`).
- **Network Configuration:** Ensure the mobile node is correctly identified within the Tailscale ACLs.

## 4. Implementation Plan (Draft)
1. **Create `scripts/provision/mobile-node-setup.sh`**.
2. **Implement modular checks:**
   ```bash
   check_tailscale() { tailscale status | grep -q "active" || return 1; }
   check_ssh() { pgrep sshd > /dev/null || return 1; }
   check_mosh() { command -v mosh-server > /dev/null || return 1; }
   ```
3. **Integrate into the Lab's Onboarding Workflow:** The script should be the first step when adding a new hardware boundary to the mesh.

## 5. Conclusion
Standardizing the Mobile Node configuration transforms a manual task into a foundational protocol, ensuring the lab's architecture remains fluid and resilient across hardware boundaries.
