### 2. The Wave64/Wave32 Divide

**CDNA (Compute DNA)**: 64-bit wavefronts - native AI/ML architecture  
**RDNA (Radeon DNA)**: 32-bit wavefronts - consumer graphics architecture

When repurposing RDNA hardware for AI workloads:
- **Wave32** (RDNA) → Consumer graphics, traditional rendering
- **Wave64** (CDNA) → AI/ML compute, tensor operations

The `HSA_ENABLE_SDMA=0` flag disables the SDMA (Synchronous DMA) engine, which is the architectural bridge that allows RDNA hardware to emulate the scheduling behavior expected by CDNA-native kernels.

### 3. The "90% Headache"

The epiphany references the "90% headache" - this is the fundamental performance gap when:
1. AI kernels designed for Wave64 (CDNA) are run on Wave32 (RDNA) hardware
2. Without the HSA flag, the scheduling mismatch causes:
   - Context switch hangs
   - Memory coherency violations
   - Kernel synchronization failures
