# Epiphany Investigation: Semantic Sanitization Layer
## Timestamp: 2025-05-22 (Simulated)
## Status: Investigating

### Hypothesis
The 'Live Scraper' or web-search functionality currently lacks a formal 'Sanitization' layer. It likely passes user-contextualized queries directly to the web, risking identity leakage. I need to find where web searches or external API calls are initiated.

### Search Strategy
1. Search for "search", "scrape", "web", "query", or "request" in `src/` and `modules/`.
2. Identify the module responsible for external communication.
3. Check if there is an existing abstraction for "queries" that can be intercepted.
### Findings
- **Target Module Identified:** `modules/sovereign_search.py` is the primary point of contact with the external web.
- **Vulnerability:** The `sovereign_search(query)` function takes a `query` directly from the user/orchestrator and passes it to `perform_search(query)`, which then uses it in `ddgs.text(query, ...)`.
- **Risk:** If a user asks "What is the price of a product that Mark's threshold allows?", the query sent to DuckDuckGo might contain "Mark's threshold", leaking private context.
- **Proposed Solution:** Introduce a `SemanticSanitizer` class or function. This function will take the high-context `query` and use an LLM (the 'Translation' step) to convert it into a 'commodity-grade' query.

### Proposed Architectural Change
1. **New Module:** `modules/semantic_sanitizer.py`
2. **Integration:**
   - Modify `modules/sovereign_search.py` to import the sanitizer.
   - In `sovereign_search(query)`, call `sanitized_query = semantic_sanitizer.sanitize(query)` before calling `perform_search(sanitized_query)`.
3. **Sanitization Logic:**
   - The sanitizer will use a prompt like: *"Convert the following user query into a generic, commodity-grade search term. Remove all personal names, specific thresholds, or private identifiers. Output ONLY the sanitized search term. User Query: {query}"*
   - This ensures the 'intelligence' (the ability to understand the user's intent) stays local, while the 'transmission' (the query sent to the web) is anonymous.

### Implementation Plan
- [ ] Create `modules/semantic_sanitizer.py`.
- [ ] Implement `sanitize(query)` using `llm_interface.query_llm`.
- [ ] Update `modules/sovereign_search.py` to use the sanitizer.
- [ ] Add a unit test to verify that "Mark's threshold for X" becomes "X price" or similar.
