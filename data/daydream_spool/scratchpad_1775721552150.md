### Proposed Architectural Change: `ExpertRelayScheduler`

**Concept:**
A scheduler that takes $\sigma_t$ (noise at timestep $t$) and returns a blending coefficient $\alpha_t$.
$$\text{Output}_t = \alpha_t \cdot \text{Expert}_{\text{High-Noise}}(\mathbf{x}_t, \sigma_t) + (1 - \alpha_t) \cdot \text{Expert}_{\text{Low-Noise}}(\mathbf{x}_t, \sigma_t)$$

**Implementation Strategy:**
1. **Define Expert Interfaces:** Create a base class `DiffusionExpert` that can be specialized for structural (macro) and textural (micro) tasks.
2. **Implement the Scheduler:** A `SigmaTransitionScheduler` that uses a non-linear decay (e.g., sigmoid or exponential) to transition $\alpha$ from $1 \to 0$ as $\sigma$ decreases.
3. **Integration:** Inject this scheduler into the `DiffLlama` forward pass or a higher-level `DiffusionPipeline`.

### Draft Proposal for `ExpertRelayScheduler`
```python
class ExpertRelayScheduler:
    def __init__(self, transition_sigma: float, smoothness: float = 1.0):
        self.transition_sigma = transition_sigma
        self.smoothness = smoothness

    def get_alpha(self, sigma: float) -> float:
        # Returns 1.0 for high noise, 0.0 for low noise
        # Uses a sigmoid-like transition around transition_sigma
        return 1.0 / (1.0 + math.exp(-self.smoothness * (sigma - self.transition_sigma)))

class RelayDiffusionModel(nn.Module):
    def __init__(self, high_noise_expert, low_noise_expert, scheduler):
        super().__init__()
        self.high_noise_expert = high_noise_expert
        self.low_noise_expert = low_noise_expert
        self.scheduler = scheduler

    def forward(self, x, sigma):
        alpha = self.scheduler.get_alpha(sigma)
        out_high = self.high_noise_expert(x, sigma)
        out_low = self.low_noise_expert(x, sigma)
        return alpha * out_high + (1 - alpha) * out_low
```
