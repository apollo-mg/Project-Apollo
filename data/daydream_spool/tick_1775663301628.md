# Architectural Audit: Presence-Absence Fallacy in Vault Tooling

## 1. Problem Statement
The current architecture suffers from a synchronization gap between the physical filesystem (`vault/cold/`) and the Vector Database (`vault/chroma_db`). The `query_vault.py` tool relies solely on the Vector DB, which may be stale if new files are added to the filesystem but the ingestion pipeline (`librarian_ingest.py`) has not been executed. This leads to "false negatives" where the system claims knowledge does not exist simply because the index is out of date.

## 2. Audit Findings
- **`query_vault.py`**: Performs similarity searches without verifying if the index matches the filesystem state.
- **`librarian_ingest.py`**: Provides the necessary ingestion logic (`ingest_makers_stack`) but is currently treated as a standalone batch process rather than a reactive service.
- **`modules/vdb.py`**: Provides access to the ChromaDB instance, which can be used to inspect metadata for synchronization checks.
- **Code Quality Issue**: `librarian_ingest.py` contains duplicate definitions of `ingest_makers_stack` and the `if __name__ == "__main__":` block, which should be cleaned up to prevent execution side-effects during imports.

## 3. Proposed Solution: State-Check Middleware

I propose implementing a synchronization bridge within `query_vault.py` that validates the index integrity before performing searches.

### Proposed Changes

#### A. Update `query_vault.py`
Integrate a `sync_vault_state()` function that:
1. Counts `.pdf` files in `vault/cold/` using `glob`.
2. Queries the Vector DB for the count of unique `filename` entries in the metadata.
3. If `files_on_disk > unique_files_in_vdb`, it triggers `librarian_ingest.ingest_makers_stack()`.

#### B. Refactor `librarian_ingest.py`
1. Remove duplicate code blocks at the end of the file.
2. Ensure `ingest_makers_stack()` is safe to call as a module function.

    COLD_VAULT_DIR = "vault/cold"
    if not os.path.exists(COLD_VAULT_DIR):
        return

    # 1. Count files on disk
    files_on_disk = len(glob.glob(os.path.join(COLD_VAULT_DIR, "**/*.pdf"), recursive=True))

Implementing this middleware transforms the Vault from a passive index into a self-healing knowledge base. This eliminates the 'Presence-Absence Fallacy' and ensures the Librarian's index always reflects the Library's shelves.
