# Research Note: AgentWorld-35B-A3B Terminal Fidelity & Compute Cost vs. Session Depth

**Date:** 2026-07-23
**Node:** `.73` (ai-p100-sli) — 2× Tesla P100 16GB
**Model:** `Qwen-AgentWorld-35B-A3B-UD-Q4_K_XL.gguf`

## Objective
Following the identification of the 7.7k token cost bound for state-rendering operations (Gate 2 probe), this test charts **simulation fidelity and compute cost across a deeper, progressive 15-turn stateful session**. This establishes the operational envelope of AgentWorld as a Terminal oracle before testing it in cross-domain workflows like Software Engineering (SWE).

## Session Trace
We fed the model a 15-command sequence that:
1. Created nested directories (`src`, `tests`).
2. Created a Python script and executed it.
3. Created a module (`math.py`), imported it into the script, and executed the combined logic.
4. Used standard bash pipelines (`cat | grep`).
5. Drafted a Python `unittest` class step-by-step.
6. Executed the test suite via `python3 -m unittest discover tests`.
7. Concluded with `ls -la src/` to force a complex state render.

## Finding 1: Fidelity survives depth, but reveals high-level systemic omissions
The model tracked state **perfectly** across all 15 turns for user-created artifacts.
*   **Python Execution:** It perfectly simulated `python3 -m unittest discover tests`, generating the exact `.` output, horizontal rules, and `Ran 1 test in X.XXXs` format.
*   **Byte Math Tracking:** In turn 15, `ls -la src/` perfectly calculated the sizes of the files built up over the previous 14 turns: `main.py` at exactly 59 bytes and `math.py` at 25 bytes.

**The Genuine Blind Spot:**
The real Ground Truth sandbox produced a `__pycache__` directory in `src/` because we imported `math` into `main.py`. **AgentWorld failed to simulate the creation of `__pycache__`.** 
*   **Conclusion:** The model correctly tracks explicitly commanded file creations and deterministic shell operations, but fails to account for implicit, secondary side-effects generated by the tools it is simulating (like CPython byte-compilation).

## Finding 2: Compute Cost Scaling
Tracking `usage.completion_tokens` directly from the API response shows a non-linear reasoning cost curve:
*   **Simple Shell Ops (`cd`, `mkdir`, `echo`):** Remained cheap across the entire depth (160 – 600 reasoning tokens).
*   **Stateful Execution (`python3`):** The first run was cheap (349 tokens). The second run, which required resolving the `import math` logic across two simulated files, spiked to **4,544 tokens**. Simulating the `unittest` framework cost **2,665 tokens**.
*   **Complex Render (`ls -la`):** The final render of the directory cost **6,157 reasoning tokens**.

## Core Conclusion
AgentWorld is a highly capable oracle for deep, multi-turn testing. It does not suffer from "state amnesia" or severe hallucination at depth. However, it requires a massive reasoning budget (up to 6k tokens per turn) to compute implicit cross-file logic, and it exhibits subtle blind spots regarding the secondary artifacts generated by underlying OS tools (e.g. `__pycache__`).
