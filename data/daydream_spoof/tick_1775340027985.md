## 1. Epiphany Analysis
The current workflow architecture (as evidenced in `legacy_vault/benchmarks/flux_rdna4_bench.py`) relies on hardcoded node types like `UNETLoader`. This creates a "Format Fragility" where switching from `.safetensors` to `.gguf` requires manual modification of the workflow JSON/dictionary. This is a tactical bottleneck that prevents seamless optimization/quantization testing.

## 2. Audit Findings
- **Observed Pattern:** Workflows are defined as static dictionaries where `class_type` is explicitly tied to a specific loader (e.g., `UNETLoader`, `CheckpointLoaderSimple`).
- **Constraint:** The logic assumes the model format is known at design time, rather than at runtime.
- **Impact:** Every time a model is quantized (e.g., to GGUF), the entire workflow structure must be re-written, increasing the risk of human error and slowing down the iteration loop.

## 3. Proposed Architectural Update: The 'Format-Agnostic Loader' (FAL)
Instead of using specific nodes, we propose a meta-node abstraction.

### A. The Logic-Gate Wrapper (Conceptual)
We should implement a `UniversalModelLoader` node. This node will:
1. **Inspect:** Check the file extension or magic bytes of the provided `model_path`.
2. **Route:** 
   - If `.safetensors` $\rightarrow$ Route to `UNETLoader` (or equivalent).
   - If `.gguf` $\rightarrow$ Route to `UnetLoaderGGUF`.
   - If `.ckpt` $\rightarrow$ Route to `CheckpointLoader`.
3. **Output:** Return the model object to the downstream `KSampler` or processing node.

### B. Implementation Strategy (Pseudo-Code)
```python
class UniversalModelLoader:
    @classmethod
    def load(cls, model_path, **kwargs):
        ext = os.path.splitext(model_path)[1].lower()
        
        if ext == ".gguf":
            return UnetLoaderGGUF(model_path, **kwargs)
        elif ext == ".safetensors":
            return UNETLoader(model_path, **kwargs)
        elif ext == ".ckpt":
            return CheckpointLoader(model_path, **kwargs)
        else:
            raise ValueError(f"Unsupported model format: {ext}")
```

## 4. Conclusion & Next Steps
The transition from "Model Type" thinking to "Model Format" thinking is required. 
**Immediate Action:** Develop a prototype `UniversalModelLoader` within the `modules` directory to allow the benchmark scripts to remain format-agnostic.
