The Memory System\nOpenClaw is famous for its **\"File-First\" memory architecture**, which rejects opaque vector databases as the primary source of truth in favor of human-readable files.[7][4]\n\n*   **Markdown as Source of Truth:** All memories are stored as plain `.md` files in a local workspace (typically `~/clawd/`).[8][4] This allows users to edit, delete, or \"git diff\" what the AI remembers.\n*   **Two-Tier Storage:**\n    *   **Ephemeral Memory (Daily Logs):** The agent automatically writes daily activity logs (`memory/YYYY-MM-DD.md`).[7][4] It typically loads \"today + yesterday\" into the active context window.\n    *   **Durable Memory (`MEMORY.md`):** A curated file for long-term facts, user preferences, and project conventions.[4]\n*   **Hybrid Retrieval:** While the files are the source of truth, OpenClaw maintains a background SQLite index that combines **BM25 (keyword search)** and **Vector Search (semantic search)** to quickly find relevant snippets from thousands of files.\n*   **Pre-Compaction Flush:** Before an LLM's context window fills up and \"forgets\" early parts of a chat, OpenClaw triggers a \"flush\" where the agent summarizes the current state and writes it to the Markdown logs.\n\n### 3.
