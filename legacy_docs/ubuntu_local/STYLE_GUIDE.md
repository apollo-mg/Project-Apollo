# PROJECT APOLLO STYLE & PREFERENCE GUIDE
*Inspired by Velvet Shark Compound Engineering*

## 🛒 PROCUREMENT PREFERENCES
- **Unit Pricing First**: All food items MUST be analyzed using Price-Per-Unit (oz/lb/gal). Never report a raw total price without a PPU benchmark.
- **Stockpile Categories**: Automatically categorize items into FREEZER_MEAT, SHELF_STABLE, or PERISHABLE.
- **Aggressive Stockpiling**: Trigger "STOCKPILE" signals for Freezer Meats/Shelf Stable if prices are within 15% of historical floors.
- **Marketing Trick Exposure**: Always "Show the Math" for BOGO, Mega Sales (Buy X Save Y), and Multi-buy (10 for $10) deals.

## 🤖 AGENTIC WORKFLOWS
- **Senior Auditor Pass**: Every deal finding must undergo a "Critique" pass to identify hidden restrictions (digital coupons, limits, membership requirements).
- **Compound Memory**: Lessons learned from failures or user corrections must be logged here immediately.
