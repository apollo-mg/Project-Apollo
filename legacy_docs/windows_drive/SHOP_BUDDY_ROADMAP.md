# ROADMAP: Project Apollo & The Buddy System
**Status:** Active Development
**Target:** A distributed, high-reasoning autonomous engineering and operational framework.
**Last Updated:** Feb 26, 2026

## 🌌 The Vision: Project Apollo
Project Apollo is the overarching portfolio and vision for all personal engineering and AI integration. It is powered by **The Buddy System**—the core backend infrastructure that manages resources, context, memory, and task routing. 
Specialized **Buddy Modules** (e.g., Shop Buddy, Code Buddy, Research Buddy) plug into this backbone to execute highly specific, fast, and effective tasks.

## ✅ Phase 0-5: Foundation & Infrastructure (COMPLETED)
*   **The Backbone:** Established the "Three-Mind Architecture" (Receptionist -> Engineer) on local hardware (RX 9070 XT, ROCm).
*   **Resource Management:** VRAM orchestration (`vram_management.py`) for swapping heavy logic/vision models.
*   **Memory & State:** "The Vault" (RAG via ChromaDB), `shop_dossier.json`, and persistent `SOUL.md`/`MEMORY.md`.
*   **Safety Interlocks:** Human-in-the-loop guardrails, Secret Scanners, and "Liar Trap" reasoning synthesis.

## 🔮 Phase 7: The Sovereign OS & Asynchronous Agency (Late 2026)
**Goal:** Transition from user-space scripts to independent, background operation.
*   **Dynamic Daemon:** Convert the Apollo Backbone to a systemd/Windows service.
*   **Asynchronous Background Loop (Cron-driven):** Modules wake up at scheduled intervals (e.g., 4 AM) to analyze logs, scan emails, or perform updates, providing a summary before the user starts the day.
*   **Obsidian "Filesystem" Integration:** Transition from ChromaDB to an Obsidian markdown vault as the primary, human-readable source of truth for all modules.
*   **Air-Gapped Interaction:** Implement a strict "Draft-Only" mode for modules interacting with email or external APIs.

## 🔮 Phase 8: The Simulator (Mid 2027 - World Models)

*   **Cognitive Digital Twins:** Physically accurate simulated replica of the shop floor for prescriptive maintenance.
*   **Physics Engine:** Integrate a lightweight physics simulator for "pre-flighting" G-code/CAD generated by the Shop Buddy module.

## 🔮 Phase 9: The Swarm (Early 2028 - Embodied Automation)

**Goal:** Replace off-the-shelf LLMs with custom-trained "Apollo-Native" models.
